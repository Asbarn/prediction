Run `spread-analytics --from 2026-01-15 --to 2026-01-15 --output json --log-dir {tmpdir}`. Parse stdout as JSON. Assert:
  - count == 5
  - net mean ~= 0.03 (epsilon 1e-6)
  - net median ~= 0.03
  - net min ~= 0.01, net max ~= 0.05
  - net stddev ~= 0.015811 (epsilon 1e-4)
  - gross mean ~= 0.06

**Test 4: `table_output_contains_expected_sections`** -- Run with default `--output table`. Assert stdout contains "Distribution Summary" and the expected formatted mean value "0.0300" (SPREAD_DP=4 decimal places). Assert exit code 0.

**Test 5: `empty_range_no_data`** -- Create an empty tempdir (no JSONL files). Run with `--from 2099-01-01 --to 2099-01-02 --log-dir {tmpdir}`. Assert exit code 0. Assert stderr contains "No spread data in range".

Assert the output still processes the 2 valid records (count == 2 in JSON output).
