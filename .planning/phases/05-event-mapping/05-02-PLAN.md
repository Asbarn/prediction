    **Create src/events/risk.rs with the following components:**

    1. **SourcePair enum** -- represents the combination of settlement sources:
       ```rust
       #[derive(Debug, Clone, PartialEq, Eq, Hash)]
       pub enum SourcePair {
           IndexIndex,      // Both use index price (lowest risk)
           IndexOracle,     // One uses index, other uses oracle
           OracleOracle,    // Both use oracles (moderate risk, different oracles)
           OracleIndex,     // Reverse of IndexOracle (same weight)
           Unknown,         // Source pair not determinable
       }
       ```
       Add `impl SourcePair { pub fn from_sources(source_a: &str, source_b: &str) -> Self }` that maps string pairs to enum variants. Map strings like "deribit_index" -> index, "oracle" -> oracle, "index" -> index.

    2. **BasisRiskScore struct:**
       ```rust
       #[derive(Debug, Clone, Serialize)]
       pub struct BasisRiskScore {
           pub settlement_time_risk: f64,  // Linear with hours difference
           pub source_risk: f64,           // Categorical weight from config
           pub criteria_risk: f64,         // Qualitative difference score
           pub composite: f64,             // Weighted sum
       }
       ```

    3. **compute_basis_risk function:**
       ```rust
       pub fn compute_basis_risk(
           settlement_time_diff_hours: f64,  // Absolute hours between Deribit settlement and prediction market resolution
           source_pair: &SourcePair,
           criteria_diff: f64,               // 0.0 = identical, 1.0 = very different
           weights: &RiskWeightsConfig,
       ) -> BasisRiskScore
       ```
       - `settlement_time_risk = settlement_time_diff_hours * weights.time_per_hour`
       - `source_risk` = lookup from `weights.source_pairs` using the SourcePair variant (use the configured values: index_index, index_oracle, oracle_oracle; for OracleIndex use same as IndexOracle)
       - `criteria_risk = criteria_diff`
       - `composite = weights.time_weight * settlement_time_risk + weights.source_weight * source_risk + weights.criteria_weight * criteria_risk`

    4. **settlement_time_diff_hours helper:**
       ```rust
       pub fn settlement_time_diff_hours(
           deribit_settlement: &str,        // ISO 8601 datetime string
           prediction_resolution: &str,     // ISO 8601 datetime string
       ) -> Option<f64>
       ```
       Parse both as `DateTime<Utc>` via `chrono::DateTime::parse_from_rfc3339`. Return `None` if either parse fails. Compute absolute difference in hours as f64.

       Also add:
       ```rust
       pub fn deribit_settlement_time(expiry_date: &str) -> Option<String>
       ```
       Given a date like "2025-06-27", return the Deribit settlement datetime string "2025-06-27T08:00:00Z" (always Friday 08:00 UTC). This is a convenience helper for mappings that only have the date.

    5. **ExpiryWarning struct and computation:**
       ```rust
       #[derive(Debug, Clone, Serialize)]
       pub struct ExpiryWarning {
           pub tier_name: String,         // "caution", "warning", "critical"
           pub hours_to_expiry: f64,
           pub flags: Vec<String>,        // ["pricing_character_change", "liquidity_warning", ...]
           pub risk_inflation_factor: f64,
       }
       ```

       ```rust
       pub fn check_expiry_warning(
           expiry_datetime: &DateTime<Utc>,
           now: &DateTime<Utc>,
           thresholds: &[ExpiryThreshold],
       ) -> Option<ExpiryWarning>
       ```
       - Compute hours_to_expiry = (expiry_datetime - now).num_minutes() as f64 / 60.0
       - If hours_to_expiry <= 0, return None (already expired)
       - Find the most severe threshold where hours_to_expiry <= threshold.hours_before_expiry
       - "Most severe" = the threshold with the smallest hours_before_expiry that is still >= hours_to_expiry (i.e., pick the tightest tier the mapping falls into)
       - Return ExpiryWarning with the matching tier's fields

    6. **inflate_risk_score function:**
       ```rust
       pub fn inflate_risk_score(
           score: &BasisRiskScore,
           inflation_factor: f64,
       ) -> BasisRiskScore
       ```
       Returns a new BasisRiskScore with settlement_time_risk multiplied by inflation_factor, and composite recalculated. Per user decision: "Near-expiry warnings both annotate the mapping AND inflate the settlement_time_risk component."

    7. **compute_risk_for_mapping convenience function:**
       ```rust
       pub fn compute_risk_for_mapping(
           mapping: &EventMapping,
           weights: &RiskWeightsConfig,
       ) -> Option<BasisRiskScore>
       ```
       Extract settlement metadata from mapping, compute source pair, compute settlement time diff, call compute_basis_risk. Return None if settlement metadata is missing or unparseable.
