<task type="auto">
  <name>Task 2: Create io.rs with DateRange and tolerant JSONL loading</name>
  <files>
    src/analysis/io.rs

  <action>
1. Create src/analysis/io.rs with:

   - `DateRange` struct with `pub from: NaiveDate` and `pub to: NaiveDate` fields.

   - `DateRange::from_args(from: Option<NaiveDate>, to: Option<NaiveDate>, last: Option<u32>) -> anyhow::Result<Self>`:
     * (Some(f), Some(t), None) -> Ok with from=f, to=t
     * (Some(f), None, None) -> Ok with from=f, to=today (chrono::Utc::now().date_naive())
     * (None, None, Some(n)) -> Ok with from=today-n days, to=today
     * (None, None, None) -> bail!("Specify --from/--to or --last N")
     * Any other combination -> bail!("Use --from/--to OR --last, not both")

   - `DateRange::files_in_dir(&self, dir: &Path) -> Vec<PathBuf>`:
     * Iterate from self.from to self.to (inclusive), construct `dir.join(format!("{}.jsonl", date.format("%Y-%m-%d")))` for each date.
     * Only include paths where `path.exists()` is true.
     * This handles spread_logs and signal_logs which both use `{YYYY-MM-DD}.jsonl` naming.

   - `DateRange::files_in_dir_prefixed(&self, dir: &Path, prefix: &str) -> Vec<PathBuf>`:
     * Same as above but constructs `dir.join(format!("{prefix}{}.jsonl", date.format("%Y-%m-%d")))`.
     * This handles settlement logs (`settlements-{YYYY-MM-DD}.jsonl`) and paper trade logs (`trades-{YYYY-MM-DD}.jsonl`) for Phase 28 use.

   - `LoadResult<T>` struct with fields: `pub records: Vec<T>`, `pub errors: usize`, `pub files_loaded: usize`, `pub files_missing: usize`.

   - `load_jsonl<T: DeserializeOwned>(files: &[PathBuf]) -> LoadResult<T>`:
     * For each file: if !exists, increment files_missing and continue. Otherwise open with BufReader, read line-by-line.
     * Skip empty/whitespace-only lines.
     * Attempt `serde_json::from_str::<T>(&line)` -- on Ok push to records, on Err increment errors.
     * Use `File::open` with proper error handling (log warning via eprintln on open failure, increment errors).

   - Implement `std::fmt::Display` for `DateRange` to show `"{from} to {to}"`.

2. Add `#[cfg(test)] mod tests` with:
   - DateRange::from_args with (Some, Some, None) returns correct range
   - DateRange::from_args with (None, None, Some(7)) returns today-7..today
   - DateRange::from_args with (None, None, None) returns Err
   - DateRange::from_args with (Some, None, Some) returns Err (conflicting)
   - load_jsonl with a temporary JSONL file containing valid lines, one malformed line, and one empty line -- verify records count, errors count
   - files_in_dir with a temp directory containing some dates -- verify only existing files returned
  </action>
