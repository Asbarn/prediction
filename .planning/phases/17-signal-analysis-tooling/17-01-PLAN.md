   ```rust
   pub fn venue_pair_label(&self) -> &'static str {
       match (self.buy_venue(), self.sell_venue()) {
           (Venue::Kalshi, Venue::Polymarket) | (Venue::Polymarket, Venue::Kalshi) => "kalshi_polymarket",
           (Venue::Deribit, Venue::Polymarket) | (Venue::Polymarket, Venue::Deribit) => "deribit_polymarket",
           (Venue::Deribit, Venue::Kalshi) | (Venue::Kalshi, Venue::Deribit) => "deribit_kalshi",
           _ => "unknown",
       }
   }
   ```

   - If `net_spread > threshold_value` -> `Some(ThresholdStatus::PassedBoth)`
   - If `net_spread > static_floor` (from threshold_components) but <= threshold_value -> `Some(ThresholdStatus::PassedStaticOnly)`
   - Otherwise -> `Some(ThresholdStatus::Filtered)`

   The SpreadEngine currently only sends results that pass threshold. Keep this behavior (only send PassedBoth on signal_tx). But set threshold_status on ALL SpreadResults that are constructed, including those that are logged but not sent.

   }

5. Implement `SignalAnalyzer`:
   - `pub fn new(config: AnalysisConfig) -> Self`
   - `pub fn record_settlement(&mut self, pos: &PaperPosition) -> AnalysisSettlementRecord`:
     - Derive venue_pair from `pos.pattern.venue_pair_label()`
     - Use `pos.threshold_status.unwrap_or(ThresholdStatus::PassedBoth)` as default
     - Compute total_net_pnl, total_raw_pnl, total_fees, total_slippage from settled_legs
     - Compute convergence_secs = `(settled_at_ms - signal_timestamp_ms) / 1000.0`
     - Determine gross_hit = raw_pnl > 0, net_hit = net_pnl > 0
     - Update AccumulatorBucket counters (total_settled, gross_hits, net_hits, sums)
     - Check stale fill
     - Compute running rates from the bucket AFTER update
     - Return AnalysisSettlementRecord with all fields populated
   - `pub fn emit_prometheus_gauges(&self)`: iterate all accumulator entries, compute rates, emit `metrics::gauge!()` with venue_pair, event_id, threshold_status labels. Skip buckets with total_settled == 0. Gauges:
     - `signal_analysis_gross_hit_rate`
     - `signal_analysis_net_hit_rate`
     - `signal_analysis_false_positive_rate`
     - `signal_analysis_avg_net_edge`
     - `signal_analysis_avg_convergence_secs`
     - `signal_analysis_total_settled`
     - `signal_analysis_stale_fill_count`
   - `pub fn export_state(&self) -> HashMap<AccumulatorKey, AccumulatorBucket>` -- for checkpoint
   - `pub fn import_state(&mut self, state: HashMap<AccumulatorKey, AccumulatorBucket>)` -- from checkpoint
   - `pub fn lifetime_summary(&self) -> LifetimeSummary` -- aggregate across all keys for daily summary log line. Returns struct with total_settled, gross_hit_rate, net_hit_rate, avg_net_edge, false_positive_rate, avg_convergence_secs, stale_fill_count.
