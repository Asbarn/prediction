<task type="auto">
  <name>Task 1: Add AMP, AMG, Grafana role, and SSM parameter to CDK stack</name>
  <files>infra/cdk/lib/prediction-stack.ts</files>
  <action>
Add imports for `aws-aps`, `aws-grafana`, and `aws-ssm` at the top of prediction-stack.ts.

After the existing CloudWatch Logging section and before the IAM section, add:

1. **AMP Workspace** using `aps.CfnWorkspace`:
   - alias: `prediction-metrics`
   - No other config needed (managed service handles storage, retention)

2. **Grafana IAM Role** using `iam.Role`:
   - assumedBy: `new iam.ServicePrincipal('grafana.amazonaws.com')`
   - description: `Amazon Managed Grafana workspace role`
   - Add inline policy granting `aps:QueryMetrics`, `aps:GetSeries`, `aps:GetLabels`, `aps:GetMetricMetadata` scoped to the AMP workspace ARN

3. **AMG Workspace** using `grafana.CfnWorkspace`:
   - accountAccessType: `CURRENT_ACCOUNT`
   - authenticationProviders: `['AWS_SSO']`
   - permissionType: `CUSTOMER_MANAGED`
   - name: `prediction-dashboards`
   - dataSources: `['PROMETHEUS']`
   - roleArn: grafanaRole.roleArn

4. **SSM Parameter** using `ssm.StringParameter`:
   - parameterName: `/prediction/amp-workspace-id`
   - stringValue: `ampWorkspace.attrWorkspaceId`
   - description: `AMP workspace ID for Prometheus remote_write configuration`

5. **CfnOutputs** for:
   - `AmpWorkspaceId` -> `ampWorkspace.attrWorkspaceId`
   - `AmpPrometheusEndpoint` -> `ampWorkspace.attrPrometheusEndpoint`
   - `GrafanaEndpoint` -> `grafanaWorkspace.attrEndpoint`
   - `GrafanaWorkspaceId` -> `grafanaWorkspace.attrId`

Also grant the EC2 instance role `ssm:GetParameter` on the SSM parameter resource (so fetch-secrets.sh can retrieve the workspace ID). Use `ssmParam.grantRead(instanceRole)`.

IMPORTANT: Place the AMP/AMG/Grafana/SSM resources AFTER the log group but BEFORE the IAM instance role section, so the AMP workspace ARN is available when constructing the Grafana role policy. The SSM grantRead call should go alongside the other instance role grants.
  </action>

  </verify>
  <done>CDK synth succeeds. cdk diff shows 4+ new resources: CfnWorkspace (APS), CfnWorkspace (Grafana), IAM Role (Grafana), SSM Parameter. No existing resources are modified except the instance role (new SSM read grant).</done>
