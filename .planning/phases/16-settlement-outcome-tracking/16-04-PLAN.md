   ```rust
   let settlement_http_client = reqwest::Client::builder()
       .timeout(std::time::Duration::from_secs(30))
       .build()
       .expect("settlement HTTP client");
   ```

2. **Build DeribitResolutionChecker** (always available -- public API, no auth):
   - Derive REST base URL from `config.venues.deribit.ws_url` by replacing the protocol and stripping the WS path: `wss://test.deribit.com/ws/api/v2` -> `https://test.deribit.com`. Use string manipulation: replace `wss://` with `https://` (or `ws://` with `http://`), then find `/ws/` and truncate.
   - Get or create Deribit rate limiter: use `pipeline_handles.venue_rate_limiters.get(&Venue::Deribit).cloned()`. If not present (Deribit rate limiter may already exist from feed pipeline), create a new one with `VenueRateLimiter::new("deribit_settlement", 5)`.
   - Construct: `DeribitResolutionChecker::new(settlement_http_client.clone(), deribit_rest_url, deribit_limiter)`
   - Insert: `checkers.insert(Venue::Deribit, VenueChecker::Deribit(deribit_checker))`

3. **Build KalshiResolutionChecker** (conditional on credentials):
   - Check if `config.credentials.kalshi_api_key_id` and `config.credentials.kalshi_private_key` (or key from `load_kalshi_key_from_file` equivalent via `config.venues.kalshi.private_key_path`) are available.
   - Follow the SAME pattern as the Kalshi feed pipeline in `src/feed/pipeline.rs` lines 221-296: get `api_key_id` from credentials, get PEM from credentials or private_key_path file, parse with `prediction::feed::kalshi::auth::load_kalshi_private_key(&pem)`.
   - Get rate limiter: `pipeline_handles.venue_rate_limiters.get(&Venue::Kalshi).cloned()` -- this was created in pipeline.rs at 5 req/s default.
   - On success: `KalshiResolutionChecker::new(settlement_http_client.clone(), config.venues.kalshi.rest_url.clone(), api_key_id, private_key, kalshi_limiter)` and insert into checkers.
   - On failure (no credentials or bad key): log `tracing::warn!` and skip -- same degradation pattern as the feed pipeline.

4. **Build PolymarketResolutionChecker** (always available -- no auth):
   - Get rate limiter: `pipeline_handles.venue_rate_limiters.get(&Venue::Polymarket).cloned()` -- created in pipeline.rs at 5 req/s default.
   - Construct: `PolymarketResolutionChecker::new(settlement_http_client.clone(), config.venues.polymarket.gamma_api_url.clone(), settlement_config.polymarket_price_lock_threshold, poly_limiter)`
   - Insert: `checkers.insert(Venue::Polymarket, VenueChecker::Polymarket(poly_checker))`

5. **Log checker registration summary:**

   ```rust
       polymarket = checkers.contains_key(&Venue::Polymarket),
       "settlement venue checkers registered"
   );
   ```
