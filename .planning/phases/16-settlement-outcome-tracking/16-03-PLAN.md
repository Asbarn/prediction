/// Settled venue legs with per-leg P&L breakdown.

3. Add `record_settled_leg(&mut self, leg: SettledLeg)` method:
- Push leg to `settled_legs`.
- If status is `Open`, transition to `PartiallySettled`.
- `settlement_pnl` is NOT set here -- it's set in `finalize_settlement`.

4. Add `all_legs_settled(&self, expected_venue_count: usize) -> bool` method:
- Return `self.settled_legs.len() >= expected_venue_count`.

5. Add `finalize_settlement(&mut self)` method:
- Compute position-level rollup from settled_legs:
  - `total_raw_pnl = sum of legs.raw_pnl`
  - `total_net_pnl = sum of legs.net_pnl`
  - `total_fees = sum of (legs.entry_fee + legs.exit_fee)`
  - `total_slippage = sum of legs.slippage_estimate`
- Set `settlement_pnl = Some(total_net_pnl)` -- net P&L is the headline number per CONTEXT.md decision.
- Set `settled_at_ms = Some(Utc::now().timestamp_millis())`.
- Set `status = PositionStatus::Settled`.

6. Add `compute_divergence(&self) -> Option<SettlementDivergence>` method:
- If settled_legs.len() < 2, return None (no cross-venue comparison possible).
- Compare OutcomeKind across legs. If any pair disagrees (e.g., one Yes, one No) -> BinaryDisagree. If outcomes agree but settlement_prices differ significantly -> PriceMismatch. If any leg is Ambiguous -> AmbiguousResolution. If resolved_at timestamps differ by > 4 hours -> TimingGap.
- Compute `actual_impact_bps` as the absolute difference in raw_pnl across legs, converted to basis points of notional.
- `basis_risk_score_at_entry` is Decimal::ZERO (will be populated by tracker which has access to BasisRiskCache).

3. Implement `fn handle_settlement(&mut self, outcome: SettlementOutcome)`:
- Find open positions matching `outcome.event_id`.
- For each matching position: compute a `SettledLeg` from the outcome:
  - `venue: outcome.venue`
  - `outcome: outcome.outcome.clone()`
  - `raw_pnl`: For the venue leg, compute `(settlement_value - entry_price) * notional * direction_sign`. For binary outcomes (Yes -> 1.0, No -> 0.0), settlement_value = 1.0 or 0.0. For Ambiguous, use `outcome.settlement_price`. The entry_price is `entry_price_buy` for the buy leg, `entry_price_sell` for the sell leg. Direction_sign depends on whether this position was buying or selling on this venue (derive from SpreadPattern).
  - `entry_fee`, `exit_fee`, `slippage_estimate`: Use the entry fee data if available on the position, otherwise Decimal::ZERO (exit is typically free for settlement).
  - `net_pnl = raw_pnl - entry_fee - exit_fee - slippage_estimate`
  - `fee_model_version: "v1.0".to_string()`
  - `resolved_at: outcome.resolved_at`, `detected_at: outcome.detected_at`
  - `resolution_source: outcome.resolution_source.clone()`
- Call `pos.record_settled_leg(leg)`.
- Determine expected_venue_count from EventRegistry lookup (count of non-None venues in EventMapping.venues).
- If `pos.all_legs_settled(expected_venue_count)`:
  - Call `pos.finalize_settlement()`.
  - Compute divergence via `pos.compute_divergence()` and set `pos.divergence`.
  - Record in aggregator: `self.aggregator.record_trade(pos)`.
  - Build `SettlementRecord` and log to JSONL via settlement logger.
  - Emit Prometheus metrics.
  - Move position to recently_settled or evict.
- If not all legs settled yet: log at DEBUG level, position stays in `open` with PartiallySettled status.

4. Add `SettlementLogger` (similar to TradeLogger):

- `log_record(&mut self, record: &SettlementRecord) -> Result<()>`.
- Same BufWriter + periodic flush pattern as TradeLogger.
- Add a `settlement_logger: SettlementLogger` field to PaperTradeTracker, initialized in `new()`.

5. Add recently_settled management:
- Add `recently_settled: VecDeque<PaperPosition>` field (capped at 100 entries or 48 hours).
- After logging SettlementRecord, push to recently_settled and evict from `open`.
- On each settlement or periodic tick, evict entries older than 48 hours from recently_settled.
- For Timeout positions: evict immediately (don't hold in recently_settled).
