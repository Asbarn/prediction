  <action>
    1. **Update src/lib.rs** to add `pub mod shutdown;` (types, error, config, logging should already be declared from Plans 01-02).

    2. **Create src/shutdown.rs** -- cross-platform signal handling:
       - `pub async fn shutdown_signal(token: CancellationToken)`:
         - On all platforms: listen for `tokio::signal::ctrl_c()`
         - On Unix only (`#[cfg(unix)]`): also listen for SIGTERM via `tokio::signal::unix::signal(SignalKind::terminate())`
         - Use `tokio::select!` to wait for any signal
         - On signal: log "received {signal_name}, initiating shutdown" at INFO level, then call `token.cancel()`
         - On Windows (`#[cfg(not(unix))]`): only ctrl_c is available
       - See research Pattern 3: Graceful Shutdown with CancellationToken for exact code.
       - Do NOT handle SIGHUP here -- config reload is handled by file watcher (cross-platform per research recommendation).
       - Use `.expect("failed to install signal handler")` for signal handler installation (true invariant -- if OS can't install signal handlers, we can't run).

    3. **Implement src/config/reload.rs** -- hot-reload via file watching:
       - `pub struct ConfigReloader` (holds internal state)
       - `pub fn start(config_dir: PathBuf, initial_config: AppConfig) -> anyhow::Result<(watch::Sender<AppConfig>, watch::Receiver<AppConfig>)>`:
         - Create `tokio::sync::watch::channel(initial_config)`
         - Spawn a `std::thread::spawn` (NOT tokio::spawn -- notify uses OS blocking APIs) that:
           - Creates a `notify_debouncer_mini::new_debouncer` with 500ms debounce duration
           - Watches `config_dir` with `RecursiveMode::NonRecursive`
           - On debounced events, checks if any changed file has `.toml` extension
           - If TOML changed: calls `load_config(&config_dir)`
             - On success: logs "config reloaded successfully" at INFO, sends new config via `watch::Sender`
             - On failure: logs "config reload failed, keeping previous: {error}" at ERROR, does NOT update channel
         - Return the watch receiver for consumers to clone
       - See research Pattern 5: Config Hot-Reload for exact code pattern.
       - The watch channel provides latest-value semantics -- consumers snapshot once per processing cycle.

    4. **Rewrite src/main.rs** -- complete binary entrypoint:
       - Use `clap` derive API for CLI:
         ```rust
         #[derive(Parser)]
         #[command(name = "prediction")]
         #[command(about = "Cross-venue prediction market arbitrage signal generator")]
         #[command(version)]
         pub struct Cli {
             #[arg(long, default_value = "config")]
             pub config_dir: PathBuf,
             #[command(subcommand)]
             pub command: Option<Commands>,
         }

         #[derive(Subcommand)]
         pub enum Commands {
             Run,
             CheckConfig,
         }
         ```
       - `#[tokio::main] async fn main() -> anyhow::Result<()>`:
         - Parse CLI args via `Cli::parse()`
         - Default command is `Run` if no subcommand given: `cli.command.unwrap_or(Commands::Run)`

         - **CheckConfig branch**:
           - Call `prediction::config::load_config(&cli.config_dir)`
           - On success: print "Configuration valid." and the three file paths, exit 0
           - On error: print "Configuration error: {e}" to stderr, exit 1

         - **Run branch**:
           - Load config (fail fast): `let config = prediction::config::load_config(&cli.config_dir)?;`
           - Initialize logging: `let _log_guard = prediction::logging::init_logging(&config.system.logging.log_dir, &config.system.logging.stdout_level, &config.system.logging.file_level)?;`
           - Log startup message: `tracing::info!(version = env!("CARGO_PKG_VERSION"), config_dir = %cli.config_dir.display(), "prediction system starting");`
           - Create shutdown token: `let shutdown_token = CancellationToken::new();`
           - Spawn shutdown signal handler: `tokio::spawn(prediction::shutdown::shutdown_signal(shutdown_token.clone()));`
           - Start config hot-reload: `let (_config_tx, _config_rx) = prediction::config::reload::ConfigReloader::start(cli.config_dir.clone(), config)?;`
           - Wait for shutdown: `shutdown_token.cancelled().await;`
           - Log shutdown complete: `tracing::info!("shutdown complete");`
           - Return Ok(()) -- `_log_guard` drops here, flushing remaining logs

       - CRITICAL: `_log_guard` must be the LAST thing dropped. Its drop impl flushes buffered logs. If it drops before the "shutdown complete" log, that message is lost.
       - Do NOT use `unwrap()` anywhere. Use `?` for propagation, `.expect()` only for true invariants.

    5. **Create .gitignore** (or update if exists):
       ```
       /target
       /logs
       *.log
       .env
       ```
       - Ignore build output, log files, and env files with secrets
       - Do NOT ignore `config/` directory (config files are not secrets)

    6. **Add `config/.gitkeep`** or ensure the config directory with example files is tracked.
