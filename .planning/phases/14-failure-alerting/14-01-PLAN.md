**src/alert/mod.rs:**
- Re-export submodules: `pub mod types;`, `pub mod config;`, `pub mod liveness;` (liveness added in Task 2)
- Re-export key types: `pub use types::{AlertCondition, AlertSeverity, ActiveAlert};`, `pub use config::AlertConfig;`

**src/alert/types.rs:**
- `AlertSeverity` enum: `Warning`, `Critical` (derive Debug, Clone, Copy, PartialEq, Eq, Serialize)
- `AlertCondition` enum with variants:
  - `FeedSilence { venue: String, silence_secs: u64, threshold_secs: u64 }` -- venue connected but no messages
  - `PartialCoverage { active_venues: usize, expected_venues: usize }` -- fewer venues than expected
  - `SignalGap { gap_secs: u64, threshold_secs: u64 }` -- no signals evaluated
  - `StageLiveness { stage: String, gap_secs: u64, threshold_secs: u64 }` -- pipeline stage not updating
  - Derive Debug, Clone, Serialize
  - Implement `Display` for human-readable alert messages
  - Implement method `fn severity(&self) -> AlertSeverity` -- FeedSilence and StageLiveness are Warning; PartialCoverage and SignalGap are Warning if within 2x threshold, Critical if beyond
  - Implement method `fn dedup_key(&self) -> String` -- unique key for deduplication (e.g., "feed_silence:deribit", "partial_coverage", "signal_gap", "stage_liveness:spread")
  - Implement method `fn prometheus_labels(&self) -> Vec<(&'static str, String)>` -- labels for metrics emission
- `ActiveAlert` struct:
  - `condition: AlertCondition`
  - `first_seen: DateTime<Utc>` -- when alert first fired
  - `last_seen: DateTime<Utc>` -- most recent evaluation that confirmed the condition
  - `count: u64` -- number of consecutive evaluations where condition was true
  - Derive Debug, Clone, Serialize

**src/alert/config.rs:**
- `AlertConfig` struct with `#[serde(default)]` and `Default` impl:
  - `enabled: bool` (default: true)
  - `check_interval_secs: u64` (default: 30) -- how often AlertMonitor runs its evaluation sweep
  - `feed_silence_threshold_secs: u64` (default: 120) -- seconds of no messages before alerting for a connected venue
  - `expected_venue_count: usize` (default: 3) -- number of venues expected to be active
  - `signal_gap_threshold_secs: u64` (default: 300) -- seconds of no signal evaluations before alerting
  - `stage_liveness_threshold_secs: u64` (default: 180) -- seconds since last pipeline stage update before alerting
  - `alert_cooldown_secs: u64` (default: 300) -- minimum seconds between repeated tracing::warn! for the same condition (prevents log spam)
  - Derive Debug, Clone, Deserialize, Serialize

**src/lib.rs:**

**src/config/system.rs:**

  <action>
Create `src/alert/liveness.rs` with a shared liveness timestamp tracker:

**src/alert/liveness.rs:**
- `PipelineLiveness` struct:
  - `last_spread_computed_at: AtomicI64` -- epoch millis of last spread computation
  - `last_signal_evaluated_at: AtomicI64` -- epoch millis of last signal evaluation (CrossAssetEngine)
  - `last_settlement_checked_at: AtomicI64` -- epoch millis of last settlement check (placeholder for Phase 16)
  - Initialize all to 0 (meaning "never")
  - Implement `PipelineLiveness::new() -> Arc<Self>` -- returns Arc-wrapped instance
  - Implement `fn record_spread(&self)` -- stores `Utc::now().timestamp_millis()` into `last_spread_computed_at` with `Ordering::Release`
  - Implement `fn record_signal_eval(&self)` -- stores timestamp into `last_signal_evaluated_at`
  - Implement `fn record_settlement_check(&self)` -- stores timestamp into `last_settlement_checked_at`
  - Implement `fn last_spread_age_secs(&self) -> Option<u64>` -- returns seconds since last spread, or None if never recorded. Uses `Ordering::Acquire` to read. Computes `(Utc::now().timestamp_millis() - stored) / 1000`. Returns None if stored value is 0.
  - Implement `fn last_signal_eval_age_secs(&self) -> Option<u64>` -- same pattern
  - Implement `fn last_settlement_check_age_secs(&self) -> Option<u64>` -- same pattern
  - Use `std::sync::atomic::{AtomicI64, Ordering}` and `chrono::Utc`
  - Derive nothing (has atomics) -- implement Debug manually to show human-readable ages
