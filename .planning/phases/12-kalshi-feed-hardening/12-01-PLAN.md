Update `KalshiMessage::parse()` to handle the nested `{type, sid, seq, msg: {...}}` envelope format:
- After parsing JSON `value`, check if `value.get("msg")` returns a `Some` with an object value
- If nested format detected: extract `type` from top-level, use `msg` object as `payload` for type-specific parsing
- If flat format: use `value` directly as `payload` (backward compat with recordings)
- For `orderbook_snapshot` and `orderbook_delta` branches, parse from `payload` instead of `value.clone()`
- For subscription ack, also check `payload`

The parse function structure becomes:
```rust
pub fn parse(text: &str) -> Self {
    let value: serde_json::Value = match serde_json::from_str(text) {
        Ok(v) => v,
        Err(_) => return KalshiMessage::Unknown(text.to_string()),
    };

    // Determine if this is wrapped (has "msg" object) or flat format
    let (msg_type_str, payload) = if let Some(msg_obj) = value.get("msg").filter(|v| v.is_object()) {
        let t = value.get("type").and_then(|t| t.as_str());
        (t.map(String::from), msg_obj.clone())
    } else {
        let t = value.get("type").and_then(|t| t.as_str());
        (t.map(String::from), value.clone())
    };

    if let Some(ref msg_type) = msg_type_str {
        match msg_type.as_str() {
            "orderbook_snapshot" => { /* parse from payload */ }
            "orderbook_delta" => { /* parse from payload */ }
            "error" => { /* parse from payload */ }
            _ => { /* unknown */ }
        }
    }
    // ... subscription ack check on payload
}
```

**3. Parse and propagate exchange_timestamp in produce_snapshot**

In `produce_snapshot()`, replace the current hardcoded `exchange_timestamp: None` and `is_stale = false` logic:

```rust
// Parse exchange timestamp from last delta's ts field (best-effort; second-precision)
// Kalshi protocol limitation: ts is ISO 8601 second-precision (no fractional seconds).
// orderbook_snapshot may not include ts, so first snapshot after connect may have None.
let exchange_ts_ms: Option<i64> = self.last_exchange_ts.get(market_ticker).and_then(|ts_str| {
    chrono::DateTime::parse_from_rfc3339(ts_str)
        .map(|dt| dt.timestamp_millis())
        .map_err(|e| {
            tracing::warn!(
                ts = %ts_str,
                error = %e,
                "failed to parse Kalshi exchange timestamp"
            );
            e
        })
        .ok()
});
```

Add `use chrono;` at the top of the file if not already imported (it is likely available since chrono is a project-wide dependency).

**4. Emit latency metrics (matching Deribit/Polymarket pattern)**
