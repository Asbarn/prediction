    1. Create src/pricing/probability.rs with:

    `fn call_spread_probability(target_strike, smile: &VolSmile, forward, time_to_expiry, rate, config: &ProbabilityConfig) -> Option<CallSpreadResult>`:
    - Use smile.nearest_bracket(target_strike) to get (k_lower, k_upper).
    - Compute epsilon = (k_upper - k_lower) / 2.0.
    - If epsilon > config.max_epsilon_usd: return None (fall back to N(d2)).
    - Interpolate IV at k_lower and k_upper from vol surface.
    - Price C(k_lower) and C(k_upper) using black76::call_price with respective IVs.
    - prob = (C(k_lower) - C(k_upper)) / (k_upper - k_lower).
    - Clamp prob to [0.0, 1.0].
    - Return CallSpreadResult { probability, epsilon_used: epsilon, k_lower, k_upper }.

    Define CallSpreadResult struct (pub(crate), Debug, Clone).

    `fn nd2_probability(forward, strike, time_to_expiry, strike_iv, atm_iv: Option<f64>) -> Nd2Result`:
    - Compute (_, d2) = black76::d1_d2(forward, strike, time_to_expiry, strike_iv).
    - prob = Normal::standard().cdf(d2) -- P(S > K) under risk-neutral measure for calls.
    - skew_adjustment = atm_iv.map(|atm| strike_iv - atm).unwrap_or(0.0).
    - Return Nd2Result { probability, skew_adjustment }.

    Define Nd2Result struct (pub(crate), Debug, Clone).

    `pub fn extract_probabilities(target_strike, smile: &VolSmile, forward, time_to_expiry, rate, config: &PricingConfig) -> ProbabilityExtraction`:
    - Compute call_spread = call_spread_probability(...).
    - Get strike_iv from smile.interpolate(target_strike).
    - Compute nd2 = nd2_probability(forward, target_strike, time_to_expiry, strike_iv, smile.atm_iv).
    - Determine primary method: if call_spread is Some, use CallSpreadReplication; else Nd2SkewAdjusted.
    - Compute method_disagreement: if both available, |call_spread.prob - nd2.prob|; else 0.0.
    - Return ProbabilityExtraction { primary_probability, primary_method, call_spread, nd2, method_disagreement, skew_adjustment }.

    Define ProbabilityExtraction struct (pub, Debug, Clone, Serialize).

    2. Add `pub mod probability;` to src/pricing/mod.rs.

    3. Write 6+ unit tests:
       a. Call spread replication with known vol smile produces expected probability

       d. N(d2) skew_adjustment computed correctly (strike_iv - atm_iv)
       e. extract_probabilities uses call spread as primary when available
       f. extract_probabilities falls back to N(d2) when call spread unavailable
       g. Method disagreement computed correctly when both methods produce different results
  </action>

    `pub fn compute_greeks(f: f64, k: f64, t: f64, sigma: f64, r: f64, is_call: bool) -> InstrumentGreeks`:
    - Compute (d1, d2) = black76::d1_d2(f, k, t, sigma).
    - df = (-r * t).exp().
    - delta: if is_call { df * N(d1) } else { df * (N(d1) - 1.0) }.
    - vega: black76::vega(f, k, t, sigma, r). Normalize to per-1%-vol-move: vega / 100.0.
    - theta (per year): for calls: df * (-(f * n(d1) * sigma) / (2.0 * t.sqrt()) - r * f * N(d1) - (-r * k * N(d2))). Divide by 365.25 for per-day theta.
    - Skip gamma per user decision.
    - If t <= 0.0: return InstrumentGreeks with delta=if is_call && f>k {1.0} else if !is_call && k>f {-1.0} else {0.0}, vega=0, theta=0.
    - Return InstrumentGreeks { delta, vega, theta }.

    Write 4+ unit tests:
    a. ATM call delta ~0.5 (for Black-76 with r=0)
    b. Deep ITM call delta ~1.0
    c. Vega is positive for non-degenerate options
    d. Put delta is negative (for OTM put)

    2. Create src/pricing/confidence.rs with:

    `pub fn compute_confidence(iv_bid_ask_spread: f64, book_depth_usd: f64, method_disagreement: f64, solver_quality: f64, config: &ConfidenceConfig) -> (f64, ConfidenceComponents)`:
    - iv_score = 1.0 - (iv_bid_ask_spread / config.iv_spread_max).min(1.0)
    - depth_score = (book_depth_usd / config.depth_target).min(1.0)
    - agreement_score = 1.0 - (method_disagreement / config.max_disagreement).min(1.0)
    - solver_score = solver_quality (pass-through, already 0.0-1.0)
    - composite = config.iv_weight * iv_score + config.depth_weight * depth_score + config.agreement_weight * agreement_score + config.solver_weight * solver_score
    - Clamp composite to [0.0, 1.0]
    - Return (composite, ConfidenceComponents { iv_spread: iv_score, book_depth: depth_score, method_agreement: agreement_score, solver_convergence: solver_score })

    Solver quality mapping (helper function):
    - `pub fn solver_quality_score(result: &SolverResult) -> f64`:
      - Converged via NR: 1.0
      - Converged via Brent: 0.6
      - Non-converged (clamped): 0.2

    b. Wide spread tanks iv_score component
    c. Large method disagreement tanks agreement_score
    d. Brent fallback reduces solver_score to 0.6
