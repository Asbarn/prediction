Implement the implied volatility solver using Newton-Raphson with Brent's method fallback, handling all edge cases: deep ITM/OTM, near-expiry theta collapse, negative time value, and configurable IV clamping.

<feature>
  <name>Implied Volatility Solver (Newton-Raphson + Brent)</name>
  <files>src/pricing/iv_solver.rs, src/pricing/mod.rs</files>
  <behavior>
    The IV solver finds the implied volatility sigma such that Black-76 model price matches the observed market price.

    Core function: `solve_iv(market_price, f, k, t, r, is_call, config) -> SolverResult`

    Cases (input -> expected output):
    - ATM call (F=100, K=100, T=1.0, market_price=7.97, r=0.0) -> IV ~0.20, method=NR, converged=true, iterations<10
    - Deep OTM call (F=100, K=200, T=0.5, market_price=0.001) -> IV solved via Brent (vega too small for NR), converged=true
    - Deep ITM put (F=100, K=50, T=0.5, market_price=49.99) -> IV near zero or clamped to iv_min, converged
    - Near-expiry (T < cutoff, e.g., T=0.0001) -> IV set to 0.0, converged=true, method reflects intrinsic pricing
    - Negative time value (market_price < intrinsic) -> IV=iv_min, converged=false, residual>0, flagged
    - IV clamping: if solver produces IV outside [iv_min, iv_max], clamp and flag
    - Zero or negative market_price -> IV=iv_min, converged=false

    Convenience function: `solve_iv_triple(bid_price, ask_price, mid_price, f, k, t, r, is_call, config) -> (SolverResult, SolverResult, SolverResult)`
    Solves bid IV, ask IV, mid IV independently. Any individual solve failure does not block the others.

    Brent's method implementation (~40 lines):
    - Bracket: [iv_min, iv_max]
    - Objective: black76::price(f, k, t, sigma, r, is_call) - market_price
    - Convergence: |f(sigma)| < price_tolerance or bracket width < 1e-12
    - Combines bisection with inverse quadratic interpolation

    Initial guess strategy:
    - Brenner-Subrahmanyam approximation: sigma_0 = sqrt(2*pi/T) * (C/F) for near-ATM
    - Clamp initial guess to [iv_min, iv_max]
    - If exchange mark_iv available, prefer that as seed (passed via optional parameter)
  </behavior>
  <implementation>
    RED phase: Write tests first for all cases above. Tests call solve_iv with known inputs and assert on convergence, IV value (within tolerance), method used, and iteration count bounds.

    GREEN phase: Implement solve_iv with:
    1. Validate inputs: t <= 0 or t < near_expiry_cutoff -> return intrinsic result
    2. Check market_price <= 0 -> return iv_min non-converged
    3. Check negative time value: market_price < intrinsic_value(f, k, is_call) -> return iv_min flagged
    4. Compute initial guess
    5. Newton-Raphson loop (up to nr_max_iterations):
       - Compute model_price = black76::price(f, k, t, sigma, r, is_call)
       - Compute v = black76::vega(f, k, t, sigma, r)
       - If |v| < vega_floor: break to Brent
       - If |model_price - market_price| < price_tolerance: return converged
       - sigma -= (model_price - market_price) / v
       - sigma = sigma.clamp(iv_min, iv_max)
    6. If NR failed, run Brent's method on [iv_min, iv_max]
    7. Return SolverResult with all metadata

    Implement brent_solve as a private helper function.
    Implement solve_iv_triple calling solve_iv three times with appropriate prices.

    REFACTOR phase: Extract Brenner-Subrahmanyam initial guess into named function. Ensure all log points are in place per user decision (solver convergence behavior feeds confidence scoring).
  </implementation>
</feature>
