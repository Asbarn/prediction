  <name>Task 1: Create DeriveProcessor for message parsing and MarketSnapshot emission</name>
  <files>

  <action>
    Create `src/feed/derive/normalize.rs` adapted from `src/feed/deribit/normalize.rs` (the template is ~1076 lines but Derive version is simpler due to snapshot-only books and no heartbeat):

    **Struct:** `DeriveProcessor` with fields:
    - `config: DeriveConfig`
    - `books: HashMap<String, DeriveBook>` (instrument_name -> book state)
    - `ticker_data: HashMap<String, DeriveTickerSlimData>` (instrument_name -> latest ticker)
    - `snapshot_tx: mpsc::Sender<MarketSnapshot>` (output channel)
    - `record_tx: Option<mpsc::Sender<RecordLine>>` (JSONL recording, optional)
    - `cleanup_rx: Option<mpsc::Receiver<CleanupEvent>>` (state cleanup on instrument removal)

    **Constructor:** `DeriveProcessor::new(config, snapshot_tx, record_tx, cleanup_rx) -> Self`

    **Method:** `pub async fn run(mut self, mut raw_rx: mpsc::Receiver<RawMessage>)`
    Main loop selects on:
    1. `raw_rx.recv()` -- process incoming raw message
    2. `cleanup_rx.recv()` -- remove books/ticker_data for removed instruments

    **Message processing flow (`process_raw`):**
    1. Parse raw text as `DeriveMessage` using `serde_json::from_str`
    2. Match on DeriveMessage variant:
       - `Response` -> log subscribe confirmation at info level
       - `Notification` -> extract channel from params, route by `DeriveChannelKind::parse`:
         - `Orderbook` -> `process_orderbook(channel, data_value, received_at)`
         - `TickerSlim` -> `process_ticker_slim(channel, data_value, received_at)`
         - `Unknown` -> debug log and skip
    3. If `record_tx` is Some, send `RecordLine { raw: text.clone(), local_ts: received_at, venue: Venue::Derive, channel, instrument }` via `try_send` (Pitfall 4 -- must wire recording)

    **Orderbook processing (`process_orderbook`):**
    1. Deserialize `data_value` as `DeriveBookData`
    2. Extract instrument name from channel using `channels::extract_instrument` (Pitfall 5)
    3. Get or create `DeriveBook` entry in `self.books`
    4. Call `book.apply_snapshot(&data)`
    5. Try to `build_snapshot` and emit

    **Ticker processing (`process_ticker_slim`):**
    1. Deserialize `data_value` as `DeriveTickerSlimWrapper` (Pitfall 6 -- outer wrapper has `instrument_ticker`)
    2. Extract instrument name from channel using `channels::extract_instrument`
    3. Store `wrapper.instrument_ticker` in `self.ticker_data`
    4. Try to `build_snapshot` and emit

    **Snapshot building (`build_snapshot`):**
    Build `MarketSnapshot` when both book AND ticker data exist for an instrument:
    - `venue: Venue::Derive`
    - `instrument_id: InstrumentId::from(instrument_name)`
    - `bid: book.best_bid().map(|(p, _)| Price::new(p))` -- USDC price, no conversion
    - `ask: book.best_ask().map(|(p, _)| Price::new(p))` -- USDC price, no conversion
    - `mark_price`: parse from ticker `M` field -> `Option<f64>` via `Decimal::from_str` then `.to_f64()`
    - `mark_iv`: parse from ticker `option_pricing.i` field
    - `bid_iv`: parse from ticker `option_pricing.bi` field
    - `ask_iv`: parse from ticker `option_pricing.ai` field
    - `underlying_price`: parse from ticker `option_pricing.f` (forward price from option_pricing, NOT top-level `f` which can be null for options -- Open Question 2)
    - `delta`: parse from ticker `option_pricing.d`
    - `gamma`: parse from ticker `option_pricing.g`
    - `vega`: parse from ticker `option_pricing.v`
    - `theta`: parse from ticker `option_pricing.t`
    - `exchange_timestamp`: from book or ticker timestamp (whichever is more recent)
    - `local_timestamp`: `DualTimestamp::now()`

    **Staleness detection (NORM-04):**
    - On each snapshot build, check if `exchange_timestamp` is older than `config.staleness_threshold_ms`
    - If stale, call `book.mark_stale()` and log at warn level, do NOT emit snapshot
    - Use the same `is_exchange_data_stale()` pattern as Deribit processor

    **Cleanup handling:**
    When `CleanupEvent` received, remove entries from `self.books` and `self.ticker_data` for instruments listed in `cleanup_event.derive_instruments`.

    **Helper function:** `fn parse_decimal_option(s: &Option<String>) -> Option<f64>` -- parses `Option<String>` to `Option<f64>` via `Decimal::from_str` -> `.to_f64()`. Returns None on parse failure or None input.

    **Update `src/feed/derive/mod.rs`**: Add `pub mod normalize;` to module declarations.

    Add unit tests:
    - `build_snapshot` with both book and ticker data produces correct MarketSnapshot
    - `build_snapshot` with missing ticker returns None (both data sources needed)
    - Stale data detection skips snapshot emission
    - Orderbook message routing correctly updates book state
    - Ticker_slim message routing correctly updates ticker state (verify wrapper deserialization)
