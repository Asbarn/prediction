## Integration Wiring (Verified by Integration Checker Agent)

### Channel Pipeline

```
Venue Supervisors (Deribit, Polymarket, Kalshi)
    └─> per-venue processors → MarketSnapshot
         └─> forward_snapshots() [event_id annotation via EventRegistry]  ← Phase 10 fix
              └─> fan-in channel (mpsc 1024)
                   └─> fan-out task
                         ├─ blocking .send()  ──> SpreadEngine
                         │     ├─ signal_tx  ──> PaperTradeTracker  [wired + event_id populated]
                         │     └─ ptrade_snap_tx  ──> PaperTradeTracker  [wired]
                         ├─ try_send()        ──> PricingEngine
                         │     └─ probability_tx  ──> CrossAssetEngine  [wired]
                         └─ try_send()        ──> CrossAssetEngine
                               └─ arb_signal_tx  ──> consumer task (INFO log + Prometheus)  ← Phase 10 fix

BasisRiskCache (Phase 11):
    ContractLifecycleManager populates cache each poll cycle
    └─> SpreadEngine reads basis_risk_premium
    └─> CrossAssetEngine reads basis_risk_premium + expiry threshold inflation

Config hot-reload (Phase 10):
    ConfigReloader → config_rx → EventRegistry.refresh() (live mode only)

VenueHealth (Phase 9 gap closure):
    All 3 supervisors → mark_available/mark_unavailable → /health endpoint
```
