**Add Polymarket question text parsing (in src/events/discovery.rs):**

1. Add `normalize_polymarket_asset(name: &str) -> Option<&'static str>` function: match `name.to_lowercase().as_str()` -- "bitcoin" -> Some("BTC"), "ethereum" | "ether" -> Some("ETH"), "solana" -> Some("SOL"), _ -> None.

2. Add `parse_polymarket_question(question: &str) -> Option<(String, Decimal, Direction)>` function following the research pattern exactly:
   - Strip leading "Will " prefix and trailing "?" suffix using `strip_prefix`/`strip_suffix`. Return None if missing.
   - Find first space to extract asset name. Call `normalize_polymarket_asset` to get ticker. Return None if unknown asset.
   - Check verb for direction: `strip_prefix("reach $")` or `strip_prefix("hit $")` -> Above; `strip_prefix("dip to $")` -> Below. Return None if no match.
   - Find " by " to isolate strike string. Remove commas from strike. Parse to Decimal via `Decimal::from_str_exact`. Return None if parse fails.
   - Return `Some((asset, strike, direction))`.
   - Note: We intentionally do NOT parse the date from the question text -- `endDateIso` from the API is the authoritative expiry source.

**Add GammaEventResponse struct:**

3. Add `GammaEventResponse` struct with `#[derive(Debug, Clone, Deserialize)]`: fields `title: Option<String>`, `markets: Vec<PolymarketMarketInfo>`. This wraps the event-level response from `/events?slug=...`.

**Add discover_polymarket_structured function:**

4. Implement `pub async fn discover_polymarket_structured(client: &reqwest::Client, gamma_api_url: &str, event_slugs: &[String], rate_limiter: Option<&VenueRateLimiter>) -> anyhow::Result<Vec<DiscoveredInstrument>>` following the research Example 1 pattern:
   - Track `seen_conditions: HashSet<String>` for deduplication across slugs (Pitfall 4).
   - For each slug: call `limiter.wait().await` if present; GET `{gamma_api_url}/events?slug={slug}`; deserialize as `Vec<GammaEventResponse>`.
   - For each market in each event: skip if condition_id already seen (dedup); skip if `!active || closed`; parse question via `parse_polymarket_question`; warn + increment `polymarket_parse_failures` counter on None; parse `end_date_iso` as NaiveDate (try both "%Y-%m-%d" and full ISO with `DateTime::parse_from_rfc3339` then `.date_naive()`); get token_id from first token with "Yes" outcome (iterate tokens, find outcome=="Yes", use that token_id; fallback to first token if no explicit "Yes"); construct DiscoveredInstrument with venue=Polymarket, instrument_id=condition_id, all parsed fields.
   - Log info with venue, slugs_polled, instruments_discovered at end.
   - Return `Ok(all)`.
