  <action>
Create `src/signal/types.rs` with these types (all derive Debug, Clone, Serialize):

1. `ArbDirection` enum: `BuyPredictionSellOptions` (prediction price < options prob, buy prediction), `SellPredictionBuyOptions` (prediction price > options prob, sell prediction). Derive Copy, PartialEq, Eq.

2. `ThresholdStatus` enum: `PassedBoth`, `PassedStaticOnly`, `Filtered`. Derive Copy, PartialEq, Eq. Per user decision: all signals logged with this status field for Phase 9 threshold effectiveness analysis.

3. `CostBreakdown` struct: `prediction_fee: Decimal`, `options_fee_estimate: Decimal`, `carry_cost: Decimal`, `prediction_slippage: Decimal`, `options_spread_cost: Decimal`, `liquidity_factor: Decimal`, `total_cost: Decimal`. All Decimal fields use `#[serde(with = "rust_decimal::serde::str")]`.

4. `LegInfo` struct: `venue: Venue`, `instrument_id: String`, `probability: Decimal` (serde str), `executable_price: Decimal` (serde str), `book_depth_levels: usize`, `fill_ratio: Decimal` (serde str).

5. `ArbSignal` struct with two sections:
   - Required fields (SGNL-05): `signal_id: String` (uuid v7), `event_id: String`, `direction: ArbDirection`, `raw_spread: Decimal`, `net_edge: Decimal`, `confidence: f64`, `prediction_leg: LegInfo`, `options_leg: LegInfo`, `timestamp: DualTimestamp`, `ttl_secs: u64`.
   - Rich metadata (per user decision): `pricing_method: PricingMethod`, `confidence_components: ConfidenceComponents`, `solver_meta: Option<SolverResult>`, `iv_spread: f64`, `skew_adjustment: f64`, `cost_breakdown: CostBreakdown`, `prediction_venue: Venue`, `threshold_status: ThresholdStatus`, `threshold_value: Decimal`, `threshold_components: Option<crate::spread::patterns::ThresholdComponents>`.
   - All Decimal fields use `#[serde(with = "rust_decimal::serde::str")]`.

Create `src/signal/config.rs` with `SignalGenerationConfig`:
- `options_staleness_ms: u64` (default 30_000 -- more lenient, Deribit options update less frequently)
- `polymarket_staleness_ms: u64` (default 5_000)
- `kalshi_staleness_ms: u64` (default 15_000)
- `signal_ttl_secs: u64` (default 30, fixed per user decision for v1)
- `target_notional: Decimal` (default 500, serde str)
- `deribit_taker_fee_rate: Decimal` (default 0.0003 = 0.03%, serde str)
- `threshold: ThresholdConfig` (reuse from spread::config)
- `rolling_window_secs: u64` (default 14400 = 4 hours)
- `log_dir: String` (default "signal_logs")
- `summary_interval_secs: u64` (default 300 = 5 minutes)
- `carry: CarryConfig` (reuse from spread::config)
- `polymarket_fees: PolymarketFeeConfig` (reuse from spread::config)
- `kalshi_fees: KalshiFeeConfig` (reuse from spread::config)

Derive Deserialize, Serialize, Debug, Clone. Use `#[serde(default)]` on struct. Implement `Default` with sensible values.

Add unit tests:
- ArbSignal serializes to JSON and back
- SignalGenerationConfig deserializes from empty TOML (defaults)
- ThresholdStatus variants are distinct
- LegInfo and CostBreakdown serialize with string Decimals

Create `src/signal/logger.rs` following the exact SpreadLogger pattern from `src/spread/logger.rs`:

`SignalLogger` struct with:
- `log_dir: PathBuf`
- `writer: Option<BufWriter<File>>`
- `current_date: Option<NaiveDate>`
- `writes_since_flush: u64`
- `flush_interval: u64` (default 100)

Methods:
- `new(log_dir: &str) -> Self` -- deferred file opening
- `async log(&mut self, signal: &ArbSignal) -> anyhow::Result<()>` -- JSON line, daily rotation, periodic flush. Note: the method is NOT actually async (no .await) but uses async fn signature to match SpreadLogger's interface for consistency.
- `flush(&mut self) -> anyhow::Result<()>` -- explicit flush
- `rotate_file(&mut self, date: NaiveDate) -> anyhow::Result<()>` -- open new date-stamped file in append mode

File naming: `{log_dir}/{YYYY-MM-DD}.jsonl` (same pattern as SpreadLogger).

Add tests:

- Logger creates directory if missing
