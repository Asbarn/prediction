  <name>Task 1: CrossAssetEngine with dual-input event loop and spread computation</name>
  <files>

  <action>
Create `src/signal/engine.rs` implementing the CrossAssetEngine following the SpreadEngine pattern but with dual inputs.

**Struct fields:**
- `latest_prob: HashMap<String, ImpliedProbability>` -- keyed by event_id (resolved from instrument_id via EventRegistry)
- `latest_pred: HashMap<(String, Venue), MarketSnapshot>` -- keyed by (event_id, venue) for prediction market snapshots
- `stats: HashMap<String, RollingStats>` -- per-event_id rolling statistics for dynamic threshold
- `config: SignalGenerationConfig`
- `logger: SignalLogger`
- `signal_count: u64`
- `filtered_count: u64`

**`new(config: SignalGenerationConfig) -> Self`:** Initialize with empty hashmaps, create SignalLogger from config.log_dir.

**`pub async fn run(mut self, mut prob_rx: mpsc::Receiver<ImpliedProbability>, mut pred_snap_rx: mpsc::Receiver<MarketSnapshot>, registry: Arc<RwLock<EventRegistry>>, cancel: CancellationToken, signal_tx: mpsc::Sender<ArbSignal>)`:**

Biased `tokio::select!` loop:
1. `cancel.cancelled()` -- log signal_count + filtered_count, break
2. `stats_interval.tick()` -- call `emit_summary()`
3. `prob_rx.recv()` -- on Some(prob): call `handle_probability(prob, &registry, &signal_tx).await`; on None: break
4. `pred_snap_rx.recv()` -- on Some(snap): call `handle_prediction_snapshot(snap, &registry, &signal_tx).await`; on None: break

**`handle_probability`:**
1. Read registry, lookup by (Venue::Deribit, instrument_id.to_string()). If unmapped, `debug!` log and increment `metrics::counter!("arb_unmapped_instruments_total")`, return.
2. Clone mapping, drop registry lock.
3. Extract event_id from mapping.
4. Insert into `latest_prob` keyed by event_id.
5. For each prediction market venue (Polymarket, Kalshi): if `latest_pred` has an entry for (event_id, venue), call `compute_and_emit(event_id, venue, &signal_tx)`.

**`handle_prediction_snapshot`:**
1. Only process Polymarket or Kalshi snapshots (skip Deribit).
2. Read registry, lookup by (venue, instrument_id.to_string()). If unmapped, return silently.
3. Clone mapping, drop lock.
4. Extract event_id.
5. Insert into `latest_pred` keyed by (event_id, venue).
6. If `latest_prob` has entry for event_id, call `compute_and_emit(event_id, venue, &signal_tx)`.

**`compute_and_emit(event_id, pred_venue, signal_tx)`:**
Core spread computation (reuses existing infrastructure):

1. Get prob from `latest_prob[event_id]` and snap from `latest_pred[(event_id, pred_venue)]`.
2. **Staleness gate:** Check ImpliedProbability timestamp age against `config.options_staleness_ms`. Check prediction market snapshot age: use `exchange_timestamp` if available, else `timestamp.wall()`, against venue-specific threshold (polymarket_staleness_ms or kalshi_staleness_ms). If either stale, log at debug, increment `metrics::counter!("arb_staleness_rejections")`, return.
3. **Extract probabilities:** `options_prob = prob.probability.into_inner()`. `pred_bid = snap.bid_probability?.into_inner()`, `pred_ask = snap.ask_probability?.into_inner()`. If either missing, return.
4. **Both directions:** For each `(ArbDirection, raw_spread_computation)`:
   - `BuyPredictionSellOptions`: raw_spread = options_prob - pred_ask (buy prediction at ask, compare with options prob)
   - `SellPredictionBuyOptions`: raw_spread = pred_bid - options_prob (sell prediction at bid)
5. **Walk prediction market book:** For BuyPrediction direction, walk asks; for SellPrediction, walk bids. Use `walk_the_book(depth, config.target_notional)`.
6. **Compute costs:**
   - `prediction_fee`: Use `polymarket_fee()` or `kalshi_taker_fee()` based on venue.
   - `options_fee_estimate`: `config.deribit_taker_fee_rate * prob.underlying_price * prob.greeks.delta.abs()` converted to Decimal. This is an approximate taker fee for the options leg.
   - `carry_cost`: `carry_cost(config.target_notional, &config.carry)`.
   - `prediction_slippage`: `(walk.avg_fill_price - top_of_book_price).abs()` where top_of_book is the bid or ask probability.
   - `options_spread_cost`: From ImpliedProbability prob_bid/prob_ask: `(prob_ask - prob_bid).abs() / 2` as half-spread cost. If either is None, use Decimal::ZERO.
   - `liquidity_factor`: For prediction market side, use `walk.fill_ratio()`. For options side, compute from bid-ask spread width: `max(0.1, 1.0 - ba_spread * 5.0)` where ba_spread is `(prob_ask - prob_bid).abs()`. Combined = `min(pred_factor, options_factor)`.
   - `total_cost = prediction_fee + options_fee_estimate + carry_cost + prediction_slippage + options_spread_cost`.
   - `net_edge = (raw_spread - total_cost) * liquidity_factor`. Per user decision, liquidity reduces effective edge, not threshold.
7. **Rolling stats:** Push net_edge_f64 to per-event RollingStats with current timestamp.
8. **Threshold evaluation:** Call `compute_threshold(rolling, &config.threshold, walk.fill_ratio(), Decimal::ONE)`. Determine ThresholdStatus:
   - `net_edge > threshold_value` -> PassedBoth
   - `net_edge > config.threshold.static_floor` -> PassedStaticOnly
   - else -> Filtered
9. **Build ArbSignal:** Use `uuid::Uuid::now_v7().to_string()` for signal_id. Populate all fields including rich metadata from ImpliedProbability (pricing_method = prob.method, confidence_components = prob.confidence_components.clone(), solver_meta = prob.solver_meta.clone(), iv_spread from prob bid/ask IVs or 0.0, skew_adjustment = prob.skew_adjustment). Set prediction_leg and options_leg LegInfo.
10. **Log to JSONL:** `self.logger.log(&signal).await` -- log ALL signals regardless of status (per user decision).
11. **Emit on channel:** Only if ThresholdStatus::PassedBoth: `signal_tx.try_send(signal)`, increment signal_count, `metrics::counter!("arb_signals_emitted_total")`.
12. **Metrics for every computation:** `metrics::histogram!("arb_signal_net_edge_bps")` with net_edge_f64 * 10000.0. `metrics::histogram!("arb_signal_confidence")` with prob.confidence. Increment `metrics::counter!("arb_computations_total")`. If filtered: increment `metrics::counter!("arb_signals_filtered_total")`.

**`emit_summary`:**
Log at info level: total events tracked (`latest_prob.len()`), total signals emitted (signal_count), total filtered (filtered_count), per-event rolling stats summary (mean edge, stddev). Emit Prometheus gauges: `arb_events_tracked`, `arb_signals_total`, `arb_filtered_total`.

**Helper `decimal_to_f64`:** Copy from spread::engine or import if made pub.

Update `src/signal/mod.rs`: add `pub mod engine;` and `pub use engine::CrossAssetEngine;`.

**Unit tests (at least 3):**
1. `staleness_gate_rejects_stale_options` -- verify old ImpliedProbability timestamp triggers rejection
2. `both_directions_computed` -- verify both ArbDirection variants are considered
3. `threshold_status_correct` -- verify PassedBoth vs PassedStaticOnly vs Filtered classification

Note: Tests should test individual methods where possible. The full `run()` method is an integration test.
