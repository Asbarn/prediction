    5. **Create src/types/decimal.rs**:
       - `Price(Decimal)` newtype: derive Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Add, Sub, From, Display, Deref, Serialize, Deserialize. Use `#[serde(with = "rust_decimal::serde::str")]` on the inner field. Use `#[display("{_0}")]`. Add `new(Decimal) -> Self` and `into_inner(self) -> Decimal` methods.
       - `Probability(Decimal)` newtype: same derives as Price. Add `new(Decimal) -> Result<Self, &'static str>` that validates 0 <= value <= 1. Add `complement(&self) -> Self` returning `Self(Decimal::ONE - self.0)`. Add `into_inner(self) -> Decimal`.
       - `Notional(Decimal)` newtype: same derives as Price. Add `new(Decimal) -> Self` and `into_inner(self) -> Decimal`.
       - Do NOT derive Mul or Div on any of these (Price*Price is meaningless per research).
       - Do NOT derive/implement DerefMut (mutations should go through explicit methods per research).
       - Implement `std::ops::Mul<Probability> for Notional` returning Notional (Notional * Probability = Notional).
       - Implement `std::ops::Mul<Price> for Notional` returning Notional if useful for downstream (position sizing).

    6. **Create src/types/ids.rs**:
       - `EventId(String)`: derive Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize, Display. Add `new(impl Into<String>) -> Self`.
       - `InstrumentId(String)`: same derives. Add `new(impl Into<String>) -> Self`.
       - `TraceId(Uuid)`: derive Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize. Add `new() -> Self` using `Uuid::now_v7()`. Manual `Display` impl showing the UUID.

    7. **Create src/types/timestamp.rs**:
       - `DualTimestamp` struct with:
         - `mono: tokio::time::Instant` -- monotonic for latency/staleness
         - `wall: chrono::DateTime<chrono::Utc>` -- wall clock for logging/serialization
       - Derive Debug, Clone (Instant is Copy, DateTime<Utc> is Copy, so struct is Copy too -- derive Copy if both fields are Copy)
       - Manual `Serialize` impl that serializes only `wall` (Instant is not serializable per research Pitfall 4)
       - `now() -> Self` capturing both clocks simultaneously
       - `elapsed(&self) -> std::time::Duration` delegating to `self.mono.elapsed()`
       - `wall(&self) -> DateTime<Utc>` getter

         - `ask_size: Option<Notional>`
         - `timestamp: DualTimestamp`
         - `sequence: u64`
         - `trace_id: TraceId`
       - Derive: Debug, Clone, Serialize
       - This is a skeleton for Phase 2; fields may expand but the structure is established.

    Do NOT use `unwrap()` anywhere in non-test code. Use `.expect("invariant: reason")` only for true invariants.
