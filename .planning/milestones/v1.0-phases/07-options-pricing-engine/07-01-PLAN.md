  <action>
    1. Create src/pricing/black76.rs implementing Black-76 in f64 space:
       - `fn d1_d2(f: f64, k: f64, t: f64, sigma: f64) -> (f64, f64)` -- compute d1 = (ln(F/K) + 0.5*sigma^2*T) / (sigma*sqrt(T)), d2 = d1 - sigma*sqrt(T)
       - `fn call_price(f: f64, k: f64, t: f64, sigma: f64, r: f64) -> f64` -- df * (F*N(d1) - K*N(d2))
       - `fn put_price(f: f64, k: f64, t: f64, sigma: f64, r: f64) -> f64` -- df * (K*N(-d2) - F*N(-d1))
       - `fn price(f: f64, k: f64, t: f64, sigma: f64, r: f64, is_call: bool) -> f64` -- dispatch to call_price/put_price
       - `fn vega(f: f64, k: f64, t: f64, sigma: f64, r: f64) -> f64` -- df * F * n(d1) * sqrt(T), where n() is the PDF
       - `fn intrinsic_value(f: f64, k: f64, is_call: bool) -> f64` -- max(0, F-K) for calls, max(0, K-F) for puts
       - Use `statrs::distribution::{ContinuousCDF, Continuous, Normal}` for Normal::standard().cdf(x) and .pdf(x).
       - Handle numerical edge: if t <= 0.0 or sigma <= 0.0, return intrinsic value.
       - All functions are pub(crate) and free functions (no struct needed).
       - Write 6+ unit tests:
         a. ATM call price matches known value (F=100, K=100, T=1.0, sigma=0.20, r=0.0 -> ~7.97)
         b. Put-call parity: call - put = df * (F - K) for various strikes
         c. Vega is positive for non-degenerate inputs
         d. Deep OTM call price near zero
         e. Near-zero T returns intrinsic value
         f. Vega matches finite-difference approximation: (price(sigma+h) - price(sigma-h)) / (2*h)

    2. Extend MarketSnapshot in src/types/snapshot.rs:
       - Add `pub bid_iv: Option<f64>` (exchange-computed bid implied volatility)
       - Add `pub ask_iv: Option<f64>` (exchange-computed ask implied volatility)
       - Add `pub underlying_price: Option<f64>` (forward/futures price used by Deribit pricer, in USD)
       - Add `pub underlying_index: Option<String>` (futures contract name, e.g., "BTC-27JUN25")
       Place these in a new section comment `// -- Options pricing data (Phase 7) --` after the greeks field.

    3. Extend TickerState in src/feed/deribit/normalize.rs:

       - Add `pub ask_iv: Option<f64>`

    4. Update any existing tests that construct MarketSnapshot (tests/smoke_test.rs and any inline tests in normalize.rs) to include the new fields with None/default values so they compile.
  </action>
