<objective>
Build the per-expiry implied volatility surface using linear interpolation with quality filtering, enabling pricing at non-traded strikes needed for call spread replication epsilon offsets.

Purpose: The vol surface is the bridge between the IV solver (which produces IV at observed strikes) and the probability extractor (which needs IV at arbitrary strikes for call spread replication). Quality filtering prevents noisy data points from corrupting interpolation, and the tier system provides clear confidence signals to downstream consumers.

Output: `src/pricing/vol_surface.rs` with VolSmile struct supporting interpolation, quality filtering, and bracket finding.
</objective>

    1. Create src/pricing/vol_surface.rs with:

    SmilePoint struct:
    - strike: f64
    - iv: f64 (mid IV from solver)
    - bid_iv: f64
    - ask_iv: f64
    - iv_spread: f64 (ask_iv - bid_iv)

    SmileQuality enum: Good (5+ usable strikes), Minimum (3-4), Degraded (fewer than 3), Empty (0 strikes).

    VolSmile struct:
    - expiry: chrono::NaiveDate
    - points: Vec<SmilePoint> (sorted by strike ascending)
    - excluded: Vec<(f64, String)> -- (strike, exclusion reason) for logging
    - quality: SmileQuality
    - atm_iv: Option<f64> -- ATM vol (nearest to forward price), used for N(d2) skew adjustment

    VolSmile::new(expiry, raw_points: Vec<SmilePoint>, config: &VolSurfaceConfig, forward_price: f64) -> Self:
    - Filter: exclude points where iv_spread > config.max_iv_spread_filter. Record excluded strikes with reason "iv_spread={spread:.2} exceeds max {max:.2}".
    - Filter: exclude points where iv <= 0.0. Record with reason "non-positive IV".
    - Sort remaining by strike ascending.
    - Determine quality tier based on remaining count vs config.min_usable_strikes and config.good_strike_count.
    - Find ATM IV: point with strike closest to forward_price.
    - If fewer than config.min_usable_strikes points remain AND atm_iv is available, set quality to Degraded (fall back to flat vol at ATM in interpolation).

    2. Add `pub mod vol_surface;` to src/pricing/mod.rs.

    3. Write 4+ unit tests:
       a. Construction with 5 good points -> SmileQuality::Good, all points retained
       b. Construction with 2 wide-spread points excluded -> remaining count determines quality
       c. Construction with < min_usable_strikes -> SmileQuality::Degraded
       d. Points are sorted by strike regardless of input order
  </action>
  <verify>
    `cargo test -p prediction --lib pricing::vol_surface` passes all construction and filtering tests.
  </verify>
  <done>

  </done>

<task type="auto">
  <name>Task 2: Linear interpolation, flat extrapolation, and bracket finding</name>
  <files>
    src/pricing/vol_surface.rs

  <action>
    1. Implement VolSmile::interpolate(&self, strike: f64) -> Option<f64>:
       - If quality is Empty: return None.
       - If quality is Degraded and atm_iv is Some: return Some(atm_iv) for any strike (flat vol fallback).
       - If only 1 point: return Some(that point's IV) for any strike.
       - If strike <= first point's strike: return Some(first point's IV) (flat extrapolation below).
       - If strike >= last point's strike: return Some(last point's IV) (flat extrapolation above).
       - Otherwise: binary search (partition_point or manual) for the two surrounding points, linear interpolate:
         `iv = iv_low + (iv_high - iv_low) * (strike - k_low) / (k_high - k_low)`

    2. Implement VolSmile::nearest_bracket(&self, target_strike: f64) -> Option<(f64, f64)>:
       - Find the nearest observed strike BELOW and ABOVE the target.
       - If target is exactly on an observed strike, use the adjacent strikes on both sides.
       - If target is below all strikes or above all strikes, return None (can't bracket).
       - Returns (k_lower, k_upper) for use as call spread replication epsilon.

    3. Implement VolSmile::skew_at(&self, strike: f64) -> Option<f64>:
       - Returns strike_iv - atm_iv (the skew magnitude at this strike relative to ATM).
       - Returns None if atm_iv is None or interpolation fails.

    4. Write 6+ unit tests:
       a. Interpolation at exact observed strike returns that IV
       b. Interpolation between two strikes returns linear blend
       c. Extrapolation below minimum strike returns first IV (flat)
       d. Extrapolation above maximum strike returns last IV (flat)
       e. nearest_bracket returns correct surrounding strikes
       f. nearest_bracket returns None for out-of-range strikes
       g. skew_at returns correct skew relative to ATM
       h. Degraded quality returns flat ATM vol for any strike
  </action>
  <verify>
