**src/spread/book_walker.rs:** Implement walk-the-book function:
- `pub fn walk_the_book(depth: &[(Price, Notional)], target_notional: Decimal) -> WalkResult`
- `WalkResult` struct: `avg_fill_price: Decimal`, `filled_notional: Decimal`, `target_notional: Decimal`, `levels_consumed: usize`
- `WalkResult::fill_ratio(&self) -> Decimal` returns filled/target (1.0 if fully filled, <1.0 if depth insufficient)
- Logic: iterate depth levels, accumulate weighted cost and filled quantity. Stop when target reached or depth exhausted. If filled > 0, avg = total_cost / total_filled. If filled == 0, return zero avg_fill_price.
- Unit tests: full fill across multiple levels, partial fill (insufficient depth), single level exactly fills, empty depth book returns zero, zero target returns zero fill.

**src/spread/rolling_stats.rs:** Implement windowed rolling statistics:
- `pub struct RollingStats` with fields: `window: VecDeque<(f64, i64)>` (value, timestamp_ms), `window_duration_ms: i64`, `sum: f64`, `sum_sq: f64`
- `RollingStats::new(window_duration_secs: u64) -> Self`
- `push(&mut self, value: f64, timestamp_ms: i64)`: evict entries older than `timestamp_ms - window_duration_ms`, then push new entry, update sum/sum_sq.
- `count(&self) -> usize`
- `mean(&self) -> f64`: sum/n (0.0 if empty)
- `stddev(&self) -> f64`: sample stddev using `(sum_sq - sum^2/n) / (n-1)`, clamped to 0.0 minimum before sqrt. Return 0.0 if n < 2.
- `percentile(&self, p: f64) -> f64`: sort window values, return linear interpolation at percentile p (0-100). For p=50 this is the median. Return 0.0 if empty.
- Unit tests: empty stats return 0, single value has mean == value and stddev == 0, known sequence (1,2,3,4,5) gives correct mean=3, stddev=~1.58, 50th percentile=3. Window eviction works (push old values, push new values outside window, old values excluded from stats). Large window holds all values.
