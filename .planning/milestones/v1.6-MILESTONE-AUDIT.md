## Tech Debt

### Phase 36: CloudWatch Logging
- `stdout_json=true` not codified in repo or CDK user-data. Set via SSM on running instance. If EC2 instance is recreated by CDK, container would default to `stdout_json=false` (human-readable), breaking structured JSON log ingestion in CloudWatch.
  - **Fix:** Add user-data step that writes `stdout_json = true` to production config.toml

### Phase 37: Prometheus + AMP + Grafana
- Grafana web UI on port 3000 open to 0.0.0.0/0 with default admin/admin credentials. Acceptable for solo trader but should be addressed if system is shared.
  - **Fix:** Restrict SG to operator IP or add basic auth

### Phase 39: Grafana Dashboards + Alerts
- ROADMAP goal says "Five dashboards" but requirements (MON-04 through MON-07) specify four. Wording discrepancy only; requirements are authoritative.
- contact-points.yml and notification-policies.yml removed due to Grafana crash with empty SMTP. Default built-in contact point used. Alerts still show state in Grafana UI.

**Total:** 4 tech debt items across 3 phases. None are blockers.

## Deviations Accepted

1. **Self-hosted Grafana OSS replaces Amazon Managed Grafana** -- AMG requires IAM Identity Center (SSO) subscription. User-approved deviation. Equivalent functionality via SigV4 auth.
2. **S3 Asset for dashboard provisioning instead of user-data heredocs** -- Dashboard JSON files exceeded 16KB user-data limit. Actually more maintainable.
