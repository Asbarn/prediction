1. Go to AWS IAM Console -> Users -> prediction-ci-deploy
2. Click "Security credentials" tab
3. Click "Create access key"
4. Select use case: "Third-party service"
5. Copy the Access Key ID and Secret Access Key

**Step 2: Get EC2 Instance ID**
- From CDK deploy output, or run: `aws ec2 describe-instances --filters "Name=tag:Name,Values=*Prediction*" --query "Reservations[0].Instances[0].InstanceId" --output text`

**Step 3: Add GitLab CI/CD Variables**
Go to GitLab -> Your Project -> Settings -> CI/CD -> Variables. Add these 3 variables:

| Variable | Value | Masked | Protected |
|----------|-------|--------|-----------|
| AWS_ACCESS_KEY_ID | (from step 1) | Yes | Yes |
| AWS_SECRET_ACCESS_KEY | (from step 1) | Yes | Yes |
| EC2_INSTANCE_ID | (from step 2) | No | Yes |

Mark all as "Protected" (only available on protected branches like master).
Mark AWS credentials as "Masked" (hidden in job logs).
