**Step 3: Create src/analysis/spread_analytics.rs with these components:**

**Result structs (all derive `Debug, Clone, Serialize`):**

1. `SpreadStats` -- count: usize, mean: f64, median: f64, stddev: Option<f64>, min: f64, max: f64, p5: f64, p25: f64, p75: f64, p95: f64
2. `DistributionSummary` -- net_spread: SpreadStats, gross_spread: SpreadStats
3. `HourlyRow` -- hour: u8, count: usize, mean: f64, median: f64, stddev: Option<f64>, pct_positive: f64
4. `HourlyBreakdown` -- rows: Vec<HourlyRow> (always exactly 24 entries, hours 0..23)
5. `VenuePairStats` -- pair_label: String, directions: BTreeMap<String, SpreadStats> (key = pattern.label()), total: SpreadStats
6. `VenuePairBreakdown` -- pairs: Vec<VenuePairStats>
7. `SpreadAnalysis` -- distribution: Option<DistributionSummary>, hourly: Option<HourlyBreakdown>, venue_pairs: Option<VenuePairBreakdown>
8. `FullSpreadOutput` -- loading: LoadingSummary, aggregate: SpreadAnalysis, by_event: Option<BTreeMap<String, SpreadAnalysis>>

**Helper function:**
- `compute_spread_stats(values: &[f64]) -> Option<SpreadStats>` -- takes a slice of f64, sorts a copy, calls mean_f64, median_f64, stddev_f64, percentile_f64 for p5/p25/p75/p95. Returns None if values is empty.

**Computation functions (pure, accept &[SpreadResult]):**

1. `compute_distribution(records: &[SpreadResult]) -> Option<DistributionSummary>` -- Extract net_spread and gross_spread via `Decimal::to_f64()` (from `rust_decimal::prelude::ToPrimitive`). Call compute_spread_stats on each. Return None if records empty.

2. `compute_hourly(records: &[SpreadResult]) -> Option<HourlyBreakdown>` -- Extract UTC hour from timestamp_ms via `chrono::DateTime::from_timestamp_millis(ts).map(|dt| dt.hour() as u8)`. Skip records with timestamp_ms <= 0 or where from_timestamp_millis returns None. Pre-populate all 24 hours. For each hour bucket, collect net_spread f64 values, compute mean/median/stddev, compute pct_positive = (count of values > 0.0) / total * 100.0. Hours with no data: count=0, mean/median/stddev/pct_positive all 0.0 (stddev = None). Return None if records empty.

3. `compute_venue_pairs(records: &[SpreadResult]) -> Option<VenuePairBreakdown>` -- Group records by `record.pattern.venue_pair_label()` using BTreeMap<&str, Vec<&SpreadResult>>. For each venue pair, sub-group by `record.pattern` using BTreeMap<SpreadPattern, Vec<&SpreadResult>>. For each sub-group, extract net_spread values and compute_spread_stats. Compute a total row for the entire venue pair. Build VenuePairStats with pair_label, directions (keyed by pattern.label()), and total. Return None if records empty.

4. `compute_analysis(records: &[SpreadResult]) -> SpreadAnalysis` -- Calls all three computation functions and assembles SpreadAnalysis.

**Formatting constants:**
- `const SPREAD_DP: usize = 4;` (4 decimal places for spread values)
- `const PERCENT_DP: usize = 1;` (1 decimal place for percentages)

**Helper:**
- `fn fmt_f64(v: f64, dp: usize) -> String` -- format!("{:.dp$}", v) with the dp parameter
- `fn fmt_opt(v: Option<f64>, dp: usize) -> String` -- map to fmt_f64 or "-"

**Table-rendering functions:**

1. `pub fn distribution_table(summary: &DistributionSummary) -> Table` -- 3 columns: "Statistic", "Net Spread", "Gross Spread". Rows: Count, Mean, Median, Std Dev, Min, Max, P5, P25, P75, P95. Numeric columns right-justified (indices 1, 2). Use SPREAD_DP for spread values, count as integer.

2. `pub fn hourly_table(breakdown: &HourlyBreakdown) -> Table` -- 6 columns: "Hour", "Count", "Mean", "Median", "Std Dev", "% Pos". 24 rows (00-23). Right-justify columns 1-5. Format hour as zero-padded 2 digits. Use SPREAD_DP for spreads, PERCENT_DP for pct_positive. Hours with count=0 show "-" for stats columns.

3. `pub fn venue_pair_table(breakdown: &VenuePairBreakdown) -> Table` -- 5 columns: "Direction", "Count", "Mean", "Median", "Std Dev". For each venue pair, insert a section_header row with the pair label (e.g., "kalshi_polymarket"), then add rows for each direction (keyed by pattern.label()), then a "TOTAL" row. Right-justify columns 1-4.

4. `pub fn analysis_tables(analysis: &SpreadAnalysis) -> Vec<(&str, Table)>` -- Returns a vec of (section_title, table) pairs for each non-None section. Titles: "Distribution Summary", "Hourly Breakdown (UTC)", "Venue Pair Breakdown".

```rust
pub fn group_by_event<'a>(records: &'a [SpreadResult]) -> BTreeMap<String, Vec<&'a SpreadResult>> {
    let mut groups: BTreeMap<String, Vec<&'a SpreadResult>> = BTreeMap::new();
    for record in records {
        groups.entry(record.event_id.clone()).or_default().push(record);
    }
    groups
}
```
