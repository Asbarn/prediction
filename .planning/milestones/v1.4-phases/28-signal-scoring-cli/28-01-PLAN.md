   `skewness_f64(values: &[f64]) -> Option<f64>` -- Fisher's bias-corrected sample skewness. Returns None if n < 3 or variance is zero. Implementation:
   - Compute mean, then m2 = sum((x - mean)^2) / n and m3 = sum((x - mean)^3) / n
   - Raw skewness g1 = m3 / m2^1.5
   - Bias correction factor = sqrt(n*(n-1)) / (n-2)
   - Return g1 * correction

   `kurtosis_f64(values: &[f64]) -> Option<f64>` -- Fisher's excess kurtosis (normal = 0). Returns None if n < 4 or variance is zero. Implementation:
   - Compute mean, m2 = sum((x - mean)^2) / n, m4 = sum((x - mean)^4) / n
   - raw_kurt = m4 / (m2 * m2)
   - Bias-corrected excess = ((n-1) / ((n-2)*(n-3))) * ((n+1)*raw_kurt - 3*(n-1))
   - Return excess

**Computation functions:**

`compute_hit_rates(records: &[AnalysisSettlementRecord]) -> Option<HitRateResult>`
- Return None if records is empty
- Count gross_hit=true and net_hit=true
- Use wilson_ci(hits, total, 1.96) for 95% and wilson_ci(hits, total, 2.576) for 99%
- Use the boolean fields directly (NOT P&L sign -- per research anti-pattern)

`compute_edge_test(pnl: &[f64]) -> Option<EdgeTestResult>`
- Return None if pnl.len() < 2
- mean = mean_f64(pnl), sd = stddev_f64(pnl), return None if sd == 0.0
- se = sd / sqrt(n), t_stat = mean / se (H0: mean = 0)
- p_value = 2.0 * (1.0 - StudentsT::new(0.0, 1.0, (n-1) as f64).cdf(t_stat.abs()))
- ci_95 = mean +/- t_crit_0.975 * se

`compute_sharpe(pnl: &[f64], first_ms: i64, last_ms: i64) -> Option<SharpeResult>`
- Return None if pnl.len() < 2 or stddev is 0
- per_trade_sharpe = mean / sd
- obs_years = (last_ms - first_ms) / (365.25 * 24 * 3600 * 1000)
- If obs_years > 0: trades_per_year = n / obs_years, annualized = per_trade * sqrt(trades_per_year)
- Else: annualized = None, trades_per_year = None
- psr = compute_psr(pnl, per_trade_sharpe)
- 365 days for prediction markets (NOT 252 stock trading days)

`compute_psr(pnl: &[f64], sharpe: f64) -> Option<f64>`
- Return None if n < 2
- Get skewness and excess kurtosis from stats functions
- raw_kurt = excess_kurt + 3.0 (convert to normal=3 convention for formula)
- PSR(0) = Phi(SR * sqrt(n-1) / sqrt(1 - skew*SR + (raw_kurt-1)/4 * SR^2))
- Return None if denominator_sq <= 0 (degenerate case)
- Use Normal::standard().cdf(z)

`compute_max_drawdown(pnl: &[f64], timestamps_ms: &[i64]) -> Option<DrawdownResult>`
- Return None if pnl is empty
- Build cumulative P&L curve (running sum)
- Walk curve tracking running peak, record max drawdown span with indices
- Find recovery: first index after trough where cumulative >= peak at max drawdown peak
- Current drawdown = overall peak - last cumulative value
- Convert indices to dates: chrono::DateTime::from_timestamp_millis(ms).format("%Y-%m-%d")
- Percentage = drawdown / peak.abs() * 100, None if peak == 0

`compute_scoring(records: &[AnalysisSettlementRecord]) -> ScoringResult`
- Convenience function that calls all five and assembles ScoringResult
- Sort records by settled_at_ms before computing (chronological order needed for drawdown and Sharpe)
- Extract pnl series once, pass to edge_test, sharpe, and drawdown
- For sharpe: first_ms = first record's settled_at_ms, last_ms = last record's settled_at_ms
- For drawdown: timestamps_ms = records.iter().map(|r| r.settled_at_ms).collect()
