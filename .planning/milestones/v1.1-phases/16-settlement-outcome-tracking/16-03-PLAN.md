3. Implement `fn handle_settlement(&mut self, outcome: SettlementOutcome)`:

- For each matching position: compute a `SettledLeg` from the outcome:
  - `venue: outcome.venue`
  - `outcome: outcome.outcome.clone()`
  - `raw_pnl`: For the venue leg, compute `(settlement_value - entry_price) * notional * direction_sign`. For binary outcomes (Yes -> 1.0, No -> 0.0), settlement_value = 1.0 or 0.0. For Ambiguous, use `outcome.settlement_price`. The entry_price is `entry_price_buy` for the buy leg, `entry_price_sell` for the sell leg. Direction_sign depends on whether this position was buying or selling on this venue (derive from SpreadPattern).
  - `entry_fee`, `exit_fee`, `slippage_estimate`: Use the entry fee data if available on the position, otherwise Decimal::ZERO (exit is typically free for settlement).
  - `net_pnl = raw_pnl - entry_fee - exit_fee - slippage_estimate`
  - `fee_model_version: "v1.0".to_string()`
  - `resolved_at: outcome.resolved_at`, `detected_at: outcome.detected_at`
  - `resolution_source: outcome.resolution_source.clone()`

  - Record in aggregator: `self.aggregator.record_trade(pos)`.
  - Build `SettlementRecord` and log to JSONL via settlement logger.
  - Emit Prometheus metrics.
  - Move position to recently_settled or evict.
- If not all legs settled yet: log at DEBUG level, position stays in `open` with PartiallySettled status.
