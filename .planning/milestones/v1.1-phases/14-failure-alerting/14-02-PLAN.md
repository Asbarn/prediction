Create `src/alert/monitor.rs` with the AlertMonitor implementation:

**AlertMonitor struct:**
```rust
pub struct AlertMonitor {
    venue_health: Vec<Arc<VenueHealth>>,
    liveness: Arc<PipelineLiveness>,
    config: AlertConfig,
    active_alerts: HashMap<String, ActiveAlert>,
    cancel: CancellationToken,
}
```

**AlertMonitor::new():**
- Accept `venue_health: Vec<Arc<VenueHealth>>`, `liveness: Arc<PipelineLiveness>`, `config: AlertConfig`, `cancel: CancellationToken`
- Initialize with empty `active_alerts` HashMap

**AlertMonitor::run(mut self):**
- Follow the standard tokio task pattern with `tokio::select! biased`:
  - Cancel branch (highest priority): log "AlertMonitor shutting down", break
  - Interval tick branch: `self.evaluate_all().await`
- Use `tokio::time::interval(Duration::from_secs(self.config.check_interval_secs))`
- Skip the first immediate tick (`.tick().await` before loop)

**AlertMonitor::evaluate_all(&mut self):**
- Call `self.check_feed_silence()` -- iterates venue_health, checks each
- Call `self.check_partial_coverage()` -- counts available venues vs expected
- Call `self.check_signal_gap()` -- reads liveness.last_signal_eval_age_secs()
- Call `self.check_stage_liveness()` -- reads liveness for spread and settlement stages
- Call `self.cleanup_resolved()` -- remove alerts from active_alerts that no longer fire
- Update Prometheus gauge: `metrics::gauge!("alert_monitor_active_alerts").set(self.active_alerts.len() as f64)`

**AlertMonitor::check_feed_silence(&mut self):**
- For each VenueHealth in self.venue_health:
  - If `vh.is_available()` AND `vh.last_message_at()` is Some(ts):
    - Compute silence_secs = (Utc::now() - ts).num_seconds() as u64
    - If silence_secs > self.config.feed_silence_threshold_secs:
      - Create `AlertCondition::FeedSilence { venue, silence_secs, threshold_secs }`
      - Call `self.fire_alert(condition)`
  - If `vh.is_available()` AND `vh.last_message_at()` is None:
    - This means connected but never received a message -- treat as silence from connection time
    - Skip for now (venue just connected, hasn't had time to stream)

**AlertMonitor::check_partial_coverage(&mut self):**
- Count venues where `is_available()` is true
- If active_count < self.config.expected_venue_count:
  - Fire `AlertCondition::PartialCoverage { active_venues: active_count, expected_venues: self.config.expected_venue_count }`

**AlertMonitor::check_signal_gap(&mut self):**
- Read `self.liveness.last_signal_eval_age_secs()`
- If Some(age) and age > self.config.signal_gap_threshold_secs:
  - Fire `AlertCondition::SignalGap { gap_secs: age, threshold_secs: self.config.signal_gap_threshold_secs }`
- If None: signal evaluation has never happened. Only alert if system has been running > threshold (check uptime or initial grace period -- skip alerting for the first `signal_gap_threshold_secs` of runtime to avoid false alarm on startup)

**AlertMonitor::check_stage_liveness(&mut self):**
- For each stage ("spread", "signal_eval", "settlement_check"):
  - Read corresponding age from PipelineLiveness
  - If Some(age) and age > self.config.stage_liveness_threshold_secs:
    - Fire `AlertCondition::StageLiveness { stage, gap_secs: age, threshold_secs }`

**AlertMonitor::fire_alert(&mut self, condition: AlertCondition):**
- Compute dedup_key from condition
- If key exists in active_alerts:
  - Update `last_seen` to now, increment `count`
  - Check cooldown: if `(now - last_warn_at) < alert_cooldown_secs`, skip tracing::warn! (suppress)
  - If cooldown expired, emit tracing::warn! again and reset cooldown
- If key is new:
  - Create ActiveAlert { condition, first_seen: now, last_seen: now, count: 1 }
  - Insert into active_alerts
  - Emit `tracing::warn!` with structured fields from the condition
  - Emit Prometheus metric: `metrics::gauge!("alert_active", "type" => type_label, labels...).set(1.0)`
- The tracing::warn! should use structured fields: `tracing::warn!(alert_type = %condition.dedup_key(), severity = ?condition.severity(), details = %condition, "alert condition detected")`

**AlertMonitor::cleanup_resolved(&mut self):**
- Iterate active_alerts and remove entries where the condition was NOT re-fired this evaluation cycle
- Track which keys were fired this cycle using a HashSet built during evaluate_all
- For resolved alerts: emit `tracing::info!` ("alert resolved"), set Prometheus gauge to 0.0
- Actually, a cleaner approach: have evaluate_all collect all fired conditions into a Vec, then in cleanup compare active_alerts keys against fired keys. Remove any active alert whose key is not in the fired set.
- To implement this cleanly, refactor evaluate_all to:
  1. Collect all conditions from check_* methods into a `Vec<AlertCondition>`
  2. Process the vec: fire new alerts, update existing, mark fired keys
  3. Cleanup: remove active alerts not in fired keys, log resolution, clear Prometheus gauge
