- For each active instrument with option_details:
  - Parse strike with `Decimal::from_str(&details.strike)` (not f64, per Phase 31 decision)
  - Parse expiry: detect seconds vs milliseconds (if value > 10_000_000_000 treat as millis, else seconds) and convert to NaiveDate via `DateTime::from_timestamp()`
  - Map option_type: match on `"C" | "call"` for Direction::Above, `"P" | "put"` for Direction::Below (handle both formats)
  - Set `asset: "BTC"`, `venue: Venue::Derive`, `is_active: true`, `extra_venue_id: None`
  - Set `raw_expiry_timestamp` to the epoch milliseconds value (convert if needed for consistency)
- Filter out instruments where `is_active` is false or `option_details` is None
- Log instrument count at INFO level: `tracing::info!(venue = "derive", count, "discovered Derive instruments")`
- Return the Vec, or propagate errors with context via anyhow

Reference `discover_deribit()` in the same file for the exact function signature pattern and error handling style.
