<task type="auto">
  <name>Task 1: Populate events.toml with near-the-money BTC mappings</name>
  <files>config/events.toml, config/config.toml</files>
  <action>
  1. First, ensure `config/config.toml` has the new `min_polymarket_price` and `max_polymarket_spread` fields in the `[discovery]` section (if they are not there, they will use defaults, which is fine -- but adding them explicitly documents the operator's intent):
     ```toml
     min_polymarket_price = 0.02
     max_polymarket_spread = 0.10
     ```

  2. Query the Polymarket Gamma API to find current near-the-money BTC contracts. Use curl:
     ```bash
     curl -s "https://gamma-api.polymarket.com/events?slug=what-price-will-bitcoin-hit-in-march-2026" | jq '.[] | .markets[] | {question, conditionId, bestBid, bestAsk, spread, tokens: [.tokens[] | {token_id, outcome}], endDateIso, active}'
     ```
     If the March 2026 slug is expired or unavailable, try April 2026 or the next available month slug. Look for contracts with bestBid >= 0.02 and near-the-money strikes.

  3. Cross-reference with Deribit instruments to find matching strikes. Use:
     ```bash
     curl -s "https://www.deribit.com/api/v2/public/get_instruments?currency=BTC&kind=option&expired=false" | jq '[.result[] | select(.strike >= 60000 and .strike <= 80000) | {instrument_name, strike, expiration_timestamp}] | sort_by(.strike) | unique_by(.strike)'
     ```

  4. For each near-the-money pair (target: $65K below/put, $70K above/call, $75K above/call -- adjust based on current BTC spot), create an EventMapping in `config/events.toml`:
     ```toml
     [[events]]
     id = "BTC-75000-2026-03-31"
     asset = "BTC"
     strike = "75000"
     direction = "above"
     expiry = "2026-03-31"
     approved = true
     status = "active"

     [events.venues.deribit]
     instrument = "BTC-28MAR26-75000-C"

     [events.venues.polymarket]
     condition_id = "0x..."
     token_id = "..."
     ```

  5. Use ACTUAL condition_id and token_id values from the Gamma API response (step 2). Do NOT use placeholder values. The token_id should be the "Yes" outcome token.

  6. For direction mapping: "above" / "reach" contracts use Calls (C suffix), "below" / "dip" contracts use Puts (P suffix).

  7. Also check if Derive has matching instruments and include as additional venue if available:
     ```bash
     curl -s "https://api.lyra.finance/public/get_instruments" -H "Content-Type: application/json" -d '{"currency":"BTC","kind":"option","expired":"false"}' | jq '[.result[] | select(.strike >= 60000 and .strike <= 80000)]'
     ```
     If Derive endpoint format differs, check `src/events/discovery.rs` for the actual Derive API URL and format.

  8. Run match-audit to validate:
     ```bash
     cargo run --bin match-audit -- --config-dir config --output table
     ```
     Fix any ERRORs. WARNs for expiry gap (Polymarket end-of-month vs Deribit Friday) are expected and acceptable.

  NOTE: BTC spot was ~$68-69K on 2026-03-09. Strikes within 10% = roughly $61K-$76K. Adjust target strikes based on current spot if significantly different. The goal is 3+ mappings in the near-the-money range.
  </action>

  </verify>
  <done>
