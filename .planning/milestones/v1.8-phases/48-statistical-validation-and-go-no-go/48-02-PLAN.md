**Types:**

2. `pub struct GoNoGoReport` (Serialize) containing:
   - `decision: GoNoGoDecision`
   - `decision_reason: String` -- one-line explanation
   - `train_range: String` -- formatted date range
   - `test_range: String` -- formatted date range
   - `train_signals: usize`
   - `test_signals: usize`
   - `raw_n: usize` -- test set raw count
   - `effective_n: usize` -- test set autocorrelation-corrected count
   - `autocorrelation: f64` -- lag-1 ACF of test set net_edge
   - `mean_edge: f64` -- mean net_edge on test set
   - `ci_95_lower: f64` -- 95% CI lower bound
   - `ci_95_upper: f64` -- 95% CI upper bound
   - `p_value: f64` -- two-tailed p-value from corrected t-test
   - `hit_rate: f64` -- fraction of test signals with net_edge > 0
   - `hit_rate_ci_95: (f64, f64)` -- Wilson CI on hit rate using n_eff
   - `sharpe_per_trade: Option<f64>` -- mean/stddev of net_edge
   - `psr: Option<f64>` -- probabilistic Sharpe ratio
   - `warnings: Vec<String>` -- advisory warnings (high ACF, low n_eff, etc.)

**Core function:**

```rust
pub fn run_go_no_go(
    signals: &[ArbSignal],
    train_range: &DateRange,
    test_range: &DateRange,
    min_effective_n: usize,
) -> GoNoGoReport
```

Implementation:
1. Split signals by timestamp: signals whose `timestamp.wall_time` (millis) falls within test_range go to test set, rest to train set. Use `NaiveDate::from` on the wall_time to compare against ranges.
2. Extract `net_edge` as f64 from test set signals: `signal.net_edge.to_string().parse::<f64>()`. Collect into Vec<f64>.
3. Call `compute_corrected_edge_test(&net_edges)` from stats.rs for the test set.
4. Compute hit rate: count of net_edge > 0.0 / total test signals. Use `wilson_ci` with `effective_n` as total (scale successes proportionally: `successes = (hit_rate * n_eff as f64).round() as usize`).
5. Compute per-trade Sharpe (mean/stddev of net_edges) and PSR using `compute_psr` from scoring.rs.
6. Build warnings vec:
   - If autocorrelation > 0.5: "HIGH autocorrelation ({rho:.3}) -- effective sample size is {pct:.0}% of raw count"
   - If effective_n < min_effective_n: "Effective sample size ({n_eff}) below minimum ({min})"
   - If test signals < 10: "Very few test signals ({n}) -- results may be unreliable"
   - If train signals == 0: "No training data found -- cannot confirm out-of-sample validity"
7. Decision logic:
   - `InsufficientData` if effective_n < min_effective_n
   - `Proceed` if CI lower bound > 0.0 (statistically significant positive edge)
   - `DoNotProceed` otherwise (edge not distinguishable from zero, or negative)
8. Set `decision_reason` to a clear one-liner explaining the decision.

**Table rendering:**

`pub fn go_no_go_table(report: &GoNoGoReport) -> Table` -- renders the report as a two-column key/value table using `output::new_table(&["Metric", "Value"])`. Sections:
- "Data Split" header: train range, test range, train signals, test signals
- "Autocorrelation" header: lag-1 ACF, raw n, effective n
- "Edge Analysis" header: mean edge (formatted to 6 decimal places), 95% CI, p-value
- "Performance" header: hit rate with CI, per-trade Sharpe, PSR
- "Decision" header: recommendation (PROCEED/DO NOT PROCEED/INSUFFICIENT DATA), reason
- Warnings printed to stderr after table

Add `pub mod go_no_go;` to `src/analysis/mod.rs`.

- `run_go_no_go` with fewer than min_effective_n signals returns `InsufficientData`
- `run_go_no_go` with high autocorrelation series includes warning about high ACF
- Decision reason is non-empty for all decision variants

Create `src/bin/go_no_go.rs` following the established CLI pattern from cost_validate.rs:

```rust
#[derive(Parser)]
#[command(name = "go-no-go")]
#[command(about = "Statistical validation and go/no-go assessment for arbitrage signals")]
struct Cli {
    #[arg(long)]
    from: Option<NaiveDate>,
    #[arg(long)]
    to: Option<NaiveDate>,
    #[arg(long)]
    last: Option<u32>,
    /// Fraction of data to hold out for testing (0.0-1.0)
    #[arg(long, default_value = "0.3")]
    test_fraction: f64,
    /// Minimum effective sample size for go decision
    #[arg(long, default_value = "30")]
    min_effective_n: usize,
    #[arg(long, default_value = "table")]
    output: OutputFormat,
    #[arg(long, default_value = "signal_logs")]
    signal_dir: PathBuf,
}
```

Main flow:
1. Parse CLI args. Resolve DateRange (default to last 30 days if no range specified, same pattern as cost_validate.rs).
2. Call `train_test_split(&range, cli.test_fraction)` to get train and test ranges.
3. Load signals from signal_dir for the full range: `range.files_in_dir(&cli.signal_dir)` then `load_jsonl::<ArbSignal>(&files)`.
4. Print loading summary to stderr: files loaded, records loaded, parse errors.
5. If no signals loaded, print error and exit 1.
6. Call `run_go_no_go(&signals, &train_range, &test_range, cli.min_effective_n)`.
7. Render output:
   - Table mode: print `go_no_go_table(&report)`, then print any warnings to stderr.
   - JSON mode: `serde_json::to_string_pretty(&report)` to stdout.
8. Exit code: 0 for Proceed, 1 for DoNotProceed, 2 for InsufficientData.

Add to Cargo.toml:
```toml

name = "go-no-go"
path = "src/bin/go_no_go.rs"
```
