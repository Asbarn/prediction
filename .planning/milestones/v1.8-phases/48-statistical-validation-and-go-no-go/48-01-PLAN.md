  <name>Task 1: Autocorrelation and effective sample size functions in stats.rs</name>
  <files>src/analysis/stats.rs</files>
  <action>
Add three new public items to `src/analysis/stats.rs`:

1. `pub fn autocorrelation_lag1(values: &[f64]) -> Option<f64>` -- Lag-1 autocorrelation coefficient. Returns None if fewer than 3 observations or zero variance. Formula: `ACF(1) = sum((x_t - mean) * (x_{t+1} - mean)) / sum((x_t - mean)^2)`. Use `.windows(2)` for the lagged product sum.

2. `pub fn effective_sample_size(n: usize, rho: f64) -> usize` -- Corrects raw sample size for serial correlation. Formula: `n_eff = n * (1 - rho) / (1 + rho)`. When `rho <= 0` or `n < 3`, return raw `n`. Minimum return value is 2 to avoid degenerate statistics.

3. `pub struct CorrectedEdgeTestResult` with fields: `mean_edge: f64`, `std_error: f64`, `t_statistic: f64`, `p_value: f64`, `ci_95: (f64, f64)`, `raw_n: usize`, `effective_n: usize`, `autocorrelation: f64`. Derive `Debug, Clone, Serialize`.

4. `pub fn compute_corrected_edge_test(values: &[f64]) -> Option<CorrectedEdgeTestResult>` -- One-sample t-test (H0: mean=0) using effective sample size. Calls `autocorrelation_lag1()` to get rho, then `effective_sample_size()` to get n_eff. Uses `n_eff` for standard error divisor (`sd / sqrt(n_eff)`) and degrees of freedom (`n_eff - 1`) in the t-distribution. Returns None if fewer than 3 values or zero standard deviation. Import `StudentsT` from `statrs::distribution` (already used in scoring.rs).

Add unit tests:
- `autocorrelation_lag1` on constant series returns None (zero variance)
- `autocorrelation_lag1` on alternating series [1, -1, 1, -1, 1] returns negative rho
- `autocorrelation_lag1` on trending series [1, 2, 3, 4, 5] returns positive rho > 0.5
- `autocorrelation_lag1` on fewer than 3 values returns None
- `effective_sample_size` with rho=0.5, n=100 returns ~33
- `effective_sample_size` with rho=0.0 returns raw n
- `effective_sample_size` with rho=-0.3 returns raw n (no correction for negative autocorrelation)
- `compute_corrected_edge_test` on known positive series returns positive mean, n_eff < raw_n when autocorrelated
- `compute_corrected_edge_test` with 2 values returns None (need 3+)

Add a `train_test_split` function to `src/analysis/io.rs`:

```
pub fn train_test_split(range: &DateRange, test_fraction: f64) -> (DateRange, DateRange)
```

Split a DateRange chronologically: first `(1 - test_fraction)` of days for training, remainder for testing.

Implementation:
1. Compute `total_days = (range.to - range.from).num_days()`. If total_days <= 0, return the full range as train with a zero-width test range (from=to=range.to).
2. `train_days = ((total_days as f64) * (1.0 - test_fraction)).floor() as i64`
3. `split_date = range.from + chrono::Duration::days(train_days)`
4. Train range: `{ from: range.from, to: split_date - chrono::Duration::days(1) }`
5. Test range: `{ from: split_date, to: range.to }`
6. Clamp test_fraction to 0.0..=1.0 before computation.

Add unit tests:
- 10-day range with test_fraction=0.3 splits into 7 train days and 3 test days
- 10-day range with test_fraction=0.5 splits into 5+5
- 1-day range returns full range as train, zero-width test
- test_fraction=0.0 gives all training, test_fraction=1.0 gives all testing
- Train.to + 1 day == Test.from (no gap, no overlap)
  </action>
