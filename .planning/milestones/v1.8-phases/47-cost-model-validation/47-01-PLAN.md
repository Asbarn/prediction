   - `derive_taker_fee_rate: Decimal` with `#[serde(default = "default_derive_taker_fee_rate")]` defaulting to `Decimal::new(4, 4)` (0.0004 = 0.04% per Derive help center docs)
   - `derive_base_fee_usd: Decimal` with `#[serde(default = "default_derive_base_fee_usd")]` defaulting to `Decimal::new(50, 2)` (0.50 USD per Derive docs)
   - Both use `#[serde(with = "rust_decimal::serde::str")]`
   - Add default functions for both
   - Update `Default` impl to include new fields
   - Update existing unit tests to verify new defaults

3. In `src/signal/engine.rs`, make options fee calculation venue-aware:
   - Around line 442-445 where `options_fee_estimate` is computed, replace the single `deribit_taker_fee_rate` usage with a venue match:
     ```rust
     let options_fee_estimate = match prob.source_venue {
         Venue::Derive => {
             let pct_fee = self.config.derive_taker_fee_rate
                 * Decimal::from_f64(prob.underlying_price).unwrap_or(Decimal::ZERO)
                 * Decimal::from_f64(prob.greeks.delta.abs()).unwrap_or(Decimal::ZERO);
             pct_fee + self.config.derive_base_fee_usd
         }
         _ => {
             self.config.deribit_taker_fee_rate
                 * Decimal::from_f64(prob.underlying_price).unwrap_or(Decimal::ZERO)
                 * Decimal::from_f64(prob.greeks.delta.abs()).unwrap_or(Decimal::ZERO)
         }
     };
     ```
   - In the total_cost calculation (around line 482), add the on-chain costs from the Polymarket fee config. The `prediction_fee` already comes from `polymarket_fee()`, so add gas and bridge costs separately:
     ```rust
     let on_chain_cost = self.config.polymarket_fees.gas_cost_usd
         + self.config.polymarket_fees.bridge_cost_amortized_usd;
     ```
     Then include `on_chain_cost` in the normalization: `(prediction_fee + options_fee_estimate + carry + on_chain_cost) / target`
   - Do NOT modify the CostBreakdown struct fields at this time -- the on-chain costs fold into `prediction_fee` conceptually (both are Polymarket-leg costs). This avoids breaking downstream JSONL parsing. Document this in a code comment.
