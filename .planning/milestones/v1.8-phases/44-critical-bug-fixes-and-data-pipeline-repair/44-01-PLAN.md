**Signal engine (src/signal/engine.rs, line ~466-471):**

Replace the total_cost and net_edge computation with normalization. The three dollar-denominated costs (`prediction_fee`, `options_fee_estimate`, `carry`) must be divided by `self.config.target_notional` before summing with probability-space costs (`prediction_slippage`, `options_spread_cost`, `basis_risk_premium`):

```rust
// Normalize dollar-denominated costs to probability space
let target = self.config.target_notional;
let total_cost = (prediction_fee + options_fee_estimate + carry) / target
    + prediction_slippage + options_spread_cost + basis_risk_premium;

// Net edge = (raw_spread - total_cost) * liquidity_factor
let net_edge = (raw_spread - total_cost) * liquidity_factor;
```

Add a `debug_assert!(target > Decimal::ZERO, "target_notional must be positive");` before the division as a safety check.

**Spread engine (src/spread/engine.rs, line ~277-280):**

The same unit mismatch exists here: `buy_fee` and `sell_fee` come from `polymarket_fee(filled_notional, ...)` or `kalshi_taker_fee(...)` which return dollars, while `sell_walk.avg_fill_price - buy_walk.avg_fill_price` is in probability space. `carry` is also in dollars.

Normalize the dollar costs:

```rust
// Normalize dollar-denominated costs to probability space
let target = self.config.target_notional;
let total_cost = (buy_fee + sell_fee + carry) / target + basis_risk_premium;

// Net spread: sell_fill_price - buy_fill_price - total_cost (all in probability space)
let net_spread = sell_walk.avg_fill_price - buy_walk.avg_fill_price - total_cost;
```

Add `debug_assert!(target > Decimal::ZERO);` before the division.

**Important:** Do NOT change any other cost computation logic. Only change how costs are combined into total_cost. The individual fee functions (polymarket_fee, kalshi_taker_fee, carry_cost) remain unchanged -- they correctly compute dollar amounts; the bug is in how those amounts are used.

If there are any existing spread engine integration tests with hardcoded expected values for net_spread, update them to reflect the corrected math (fees divided by target_notional).
