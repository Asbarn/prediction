<objective>
Make the CrossAssetEngine write SpreadResult entries to spread_logs so downstream analysis phases have spread data for Polymarket-vs-options pairs.

Purpose: With Kalshi disabled, the SpreadEngine (which pairs Polymarket-vs-Kalshi) never produces output. The CrossAssetEngine already computes Polymarket-vs-options spreads for signal_logs. By also writing SpreadResult to spread_logs, we satisfy the requirement without a risky SpreadEngine refactor. This is the minimal approach recommended by research (Pitfall 5: avoid scope creep).

Output: CrossAssetEngine produces spread_logs JSONL alongside signal_logs. SpreadPattern enum extended with cross-asset variants.
</objective>

**Write SpreadResult after each signal computation:**

In the `handle_implied_probability` method (or wherever the ArbSignal is constructed, around line ~526-570), after building the `ArbSignal`, also construct and log a `SpreadResult`:

```rust
// Map ArbDirection to cross-asset SpreadPattern
let spread_pattern = match direction {
    ArbDirection::BuyPredictionSellOptions => SpreadPattern::BuyPredictionSellOptionsImplied,
    ArbDirection::SellPredictionBuyOptions => SpreadPattern::SellPredictionBuyOptionsImplied,
};

let spread_result = SpreadResult {
    event_id: event_id.to_string(),
    pattern: spread_pattern,
    gross_spread: raw_spread,
    net_spread: net_edge,
    buy_fill_price: if matches!(direction, ArbDirection::BuyPredictionSellOptions) {
        walk.avg_fill_price
    } else {
        options_executable
    },
    sell_fill_price: if matches!(direction, ArbDirection::BuyPredictionSellOptions) {
        options_executable
    } else {
        walk.avg_fill_price
    },
    buy_fee: if matches!(direction, ArbDirection::BuyPredictionSellOptions) {
        prediction_fee / self.config.target_notional
    } else {
        options_fee_estimate / self.config.target_notional
    },
    sell_fee: if matches!(direction, ArbDirection::BuyPredictionSellOptions) {
        options_fee_estimate / self.config.target_notional
    } else {
        prediction_fee / self.config.target_notional
    },
    carry_cost: carry / self.config.target_notional,
    total_cost,  // already normalized from Plan 01
    basis_risk_premium,
    buy_fill_ratio: if matches!(direction, ArbDirection::BuyPredictionSellOptions) {
        walk.fill_ratio()
    } else {
        Decimal::ONE
    },
    sell_fill_ratio: if matches!(direction, ArbDirection::BuyPredictionSellOptions) {
        Decimal::ONE
    } else {
        walk.fill_ratio()
    },
    target_notional: self.config.target_notional,
    timestamp_ms: now_ms,
    poly_exchange_ts: Some(snap.exchange_timestamp.unwrap_or(now_ms)),
    kalshi_exchange_ts: None,
    options_exchange_ts: Some(now_ms),  // options prob timestamp
    threshold: Some(threshold_value),
    threshold_components: Some(components.clone()),
    threshold_status: Some(threshold_status),
};

if let Err(e) = self.spread_logger.log(&spread_result).await {
    tracing::warn!(error = %e, "failed to write cross-asset spread log");
}
```

**IMPORTANT notes:**
- The `total_cost` used here is the already-normalized value from Plan 01 (FIX-01 fix). The individual fee fields in SpreadResult are also normalized (divided by target_notional) since SpreadResult fields represent probability-space values per the spread engine convention.
- Place the SpreadResult construction AFTER the ArbSignal construction (so we reuse the same computed values).
- The `components` variable from `compute_threshold()` needs to be cloned since it's used in both ArbSignal and SpreadResult.
